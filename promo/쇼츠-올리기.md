# 쇼츠 올리기

영상은 `promo/video/`에 있다.

**5일차부터는 새로 뽑아야 한다.** 지금 있는 건 넷뿐이다. 문제를 바꿔가며 뽑는다.

```
node scripts/shorts-gen.mjs match 137           성냥개비 137번 문제
node scripts/shorts-gen.mjs discover 20666:1    8/2 아카이브 두 번째 발견형
node scripts/shorts-gen.mjs trivia 20665:2      8/1 아카이브 세 번째 상식
```

성냥개비만 741개고, 발견형과 상식은 아카이브가 하루씩 늘어난다.
문제가 바뀌면 아래 설명의 문제 내용도 같이 고쳐야 한다.

## 한 번에 다 올리지 않는다

신규 계정이 영상을 몰아서 올리면 알고리즘이 잘 안 밀어준다. 무엇보다
**어느 유형이 먹히는지 알 수 없게 된다.** 하루 하나씩, 센 것부터.

| 순서 | 영상 | 왜 이 순서인가 |
|---|---|---|
| 1일차 | 성냥개비 | 초록 전광판이 화면에서 제일 튀고, 성냥이 날아가는 게 명확하다 |
| 2일차 | 전개도 | 접히는 과정이 오묘하게 만족스럽다. 끝까지 봐야 답을 안다 |
| 3일차 | 발견형 | 규칙 찾는 재미는 있는데 글씨가 작다 |
| 4일차 | 상식 | 제일 약하다. 앞의 셋 반응을 보고 올릴지 정해도 된다 |

## 어디에

**인스타그램 릴스** — 계정이 이미 있으니 제일 쉽다. 올리면서 음악을 고른다.
인기 음원을 쓰면 도달에 유리하고, 원본 소리(째깍째깍)와의 볼륨 비율은
릴스 편집기에서 조절된다.

**유튜브 쇼츠** — 채널을 새로 만들어야 한다. youtube.com에서 devcom21c 계정으로
5분이면 된다. 이름은 `딸깍`. 올린 뒤 Studio → 오디오 보관함에서 트랙을 얹으면
원본 소리와 섞인다.

**스레드** — 영상도 올라간다. 이미 사람이 조금 붙어 있으니 여기가 제일 먼저
반응이 올 수도 있다.

세로 1080×1920이라 세 곳 다 그대로 쓴다.

## 성냥개비

**제목 / 릴스 첫 줄**
```
성냥 하나만 옮겨서 참으로 만들 수 있나요?
```

**설명**
```
0 + 8 = 3

성냥 하나를 집어서 다른 자리에 놓으면 참이 됩니다.
부러뜨리거나 빼면 안 돼요.

이런 문제가 741개 있습니다. 전부 프로그램이 만들고 프로그램이 검증했어요.
답이 하나뿐이라는 것도 코드가 보증합니다.

ddalkkak.app/matchstick
```

**해시태그**
```
#성냥개비퍼즐 #두뇌퍼즐 #브레인티저 #퍼즐 #문제풀이 #딸깍 #shorts
```

```

```

**설명**

머릿속에서 종이를 접어 보는 문제입니다.
규칙을 외워서 푸는 게 아니라 도형을 실제로 돌려봐야 풀려요.

틀리면 진짜로 접히는 과정을 3D로 보여줍니다.
몇 번만 해보면 감이 옵니다.

## 발견형

**제목 / 릴스 첫 줄**
```
규칙이 보이시나요? 5+8=?
```

**설명**
```
4+6=46
3+5=35
3+4=43
6+2=62
5+8=?

규칙을 알려주지 않습니다. 예시만 보고 스스로 찾아야 해요.
막히면 힌트가 시간차로 3단계 열립니다. 바로 답은 못 봅니다.

이런 문제를 303개 모아뒀습니다.

ddalkkak.app/discover
```

**해시태그**
```
#규칙찾기 #두뇌퍼즐 #브레인티저 #수열 #문제풀이 #딸깍 #shorts
```
