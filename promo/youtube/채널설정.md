# 유튜브 채널 설정

기존 채널(엔티, 랩·힙합 커버)을 딸깍으로 바꾼다. 이미지는 이 폴더에 있고
`node scripts/youtube-assets.mjs`로 다시 만든다.

## 올릴 파일

| 항목 | 파일 | 유튜브 요구 |
|---|---|---|
| 프로필 사진 | `프로필.png` | 98×98 이상, 4MB 이하 → **800×800, 21KB** |
| 배너 이미지 | `배너.png` | 2048×1152 이상, 6MB 이하 → **2048×1152, 94KB** |
| 동영상 워터마크 | `워터마크.png` | 150×150 권장, 1MB 이하 → **150×150, 11KB, 배경 투명** |

배너는 기기마다 보이는 범위가 다르다. 글자는 전부 가운데 1546×423 안에 넣었으니
휴대폰에서도 안 잘린다.

## 순서

1. **프로필** 탭에서 사진·배너 업로드, 이름·핸들·설명·링크·이메일 입력 → `게시`
2. 좌측 메뉴 **설정 → 채널 → 브랜딩** 에서 동영상 워터마크 업로드
   (표시 시점은 `동영상 전체`가 무난하다)
3. **설정 → 채널 → 기본 정보** 에서 키워드 추가

키워드(쉼표로 구분):

```
두뇌퍼즐, 브레인티저, 상식퀴즈, 성냥개비퍼즐, 전개도, 공간지각, 퍼즐, 문제풀이, 딸깍
```

## 기존 채널을 바꿀 때 주의

- 이전 영상(랩·힙합 커버)이 남아 있으면 새 구독자에게 섞여 보인다.
  비공개로 돌리거나 삭제하는 게 깔끔하다.
- 재생목록·설명에 남은 이전 내용도 같이 정리한다.
