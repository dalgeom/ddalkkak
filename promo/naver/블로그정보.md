# 네이버 블로그 — 관리 › 기본설정 › 블로그 정보

이미지는 `node scripts/naver-assets.mjs` 로 만든다.

---

## 위에서부터 차례로

### 연령그룹

**☑ 체크한다.**

체크하면 네이버가 같은 연령대 사용자에게 글을 추천해 준다. 노출 창구가 하나 늘어나는 것이고, 다른 연령대를 막지는 않는다. 새 블로그는 노출 기회를 하나라도 더 잡는 쪽이 맞다.

### 블로그명 — 25자 이내

```
딸깍 : 매일 두뇌 퍼즐 10문제
```

`두뇌 퍼즐`을 넣은 이유가 있다. 블로그명은 네이버 검색 결과에 그대로 뜨고, 블로그 자체가 검색에 잡히는 데 쓰인다. `ddalkkak_app님의 블로그`로는 아무것도 안 걸린다.

### 별명 — 10자 이내

```
딸깍 만드는 사람
```

글쓴이 이름으로 붙는다. 카테고리명(`딸깍 만드는 이야기`)과 글의 독백체에 맞췄다.

### 소개글 — 200자 이내

```
매일 자정에 두뇌 퍼즐 10문제가 열리는 사이트 '딸깍'을 혼자 만들고 있습니다.

발견형 퍼즐 · 상식 퀴즈 · 성냥개비 · 전개도 — 지금까지 2,161문제.
로그인도 서버도 없이 브라우저 안에서만 돌아갑니다.

만들면서 넘어진 이야기를 여기에 적습니다.

ddalkkak.app
```

약 150자. 소개글은 링크가 안 걸리지만 주소를 봐두는 사람이 있어서 넣었다.

### 내 블로그 주제 ●

**지식·동향 › IT컴퓨터**

필수 항목이다. 비어 있으면 네이버 주제별 홈에 아예 안 뜬다. 카테고리 주제분류와 같은 값으로 맞춘다.

### 블로그 프로필 이미지

```
promo/naver/프로필.png   (800x800)
```

가로 161px 썸네일로 줄어든다. 그래서 글자를 안 넣었다 — 그 크기에서는 뭉개지고, 어차피 별명이 옆에 같이 나온다.

`☐ 네이버 프로필에도 적용합니다` 는 **체크하지 않는다.** 네이버 전체 계정 프로필까지 바뀐다. 카페·지식iN 등 다른 서비스에서 쓰는 얼굴이라 블로그와 분리해 두는 게 낫다.

### 모바일앱 커버 이미지

```
promo/naver/커버.png   (1200x1600)
```

지금 들어있는 분홍 구름은 네이버 기본값이다. 바꾼다.

기기 해상도에 맞춰 잘리는데 어디가 잘릴지 정해져 있지 않다. 그래서 글자를 전부 **가운데 세로 900px 안**에 넣었다. 위아래는 배경 무늬만 있어서 잘려도 상관없다.

### 사업자 확인

**할 것 없다.** 블로그로 물건을 팔지 않는다.
