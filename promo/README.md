# 홍보 자료

딸깍을 알리는 데 쓰는 것들. 배포되지 않는다 — `static/`이 아니라 저장소에만 있다.

```
promo/
  images/           스크린샷 (프로덕트 등록·SNS 첨부용)
  video/            쇼츠·릴스
  스레드-첫주.md     스레드 7일치 초안
  쇼츠-올리기.md     쇼츠 제목·설명·해시태그, 올리는 순서
```

## video

유형마다 하나씩. 넷 다 1080×1920, 10.6초, 소리 있음.

| 파일 | 문제 | 출처 |
|---|---|---|
| `쇼츠-전개도.mp4` | 접으면 어떤 주사위가 될까 | `/cubenet/guide`의 고정 예제 |
| `쇼츠-성냥개비.mp4` | `0 + 8 = 3` → `0 + 9 = 9` | `/matchstick?p=42` |
| `쇼츠-발견형.mp4` | `4+6=46 … 5+8=?` | `/archive/20668` |
| `쇼츠-상식.mp4` | 애국가를 작곡한 사람은 | `/archive/20668` |

**다시 만들기**

```
node scripts/shorts-gen.mjs            네 개 모두
node scripts/shorts-gen.mjs cube       하나만 (cube·match·discover·trivia)
```

합성 화면이 아니라 실제 딸깍을 헤드리스 브라우저로 찍는다. 문제가 매번 달라지면
다시 만들 수 없으므로 고정된 주소만 쓴다 — 전개도는 가이드의 고정 예제,
성냥개비는 `?p=번호`, 발견형과 상식은 지난 문제(날짜로 고정)다.

앱이 직접 움직이는 유형은 그 과정을 한 프레임씩 찍는다.

  전개도    접기 슬라이더를 코드로 밀어 진행도를 통제한다
  성냥개비  정답 보기를 누르면 성냥이 집혔다 날아가 안착한다

그래서 영상 속 움직임이 앱에서 보는 것과 완전히 같다. 발견형과 상식은 문제와
정답 두 장만 찍고, 사이를 채우는 건 ffmpeg가 한다.

**움직임** — 정지 화면 두 장을 이어 붙이면 슬라이드쇼지 영상이 아니다.

```
0.00~0.35s  등장       아래에서 올라오며 서서히 나타난다
0.00~5.50s  숨 고르기  아주 천천히 확대된다(Ken Burns)
0.00~5.50s  시간 막대  화면 맨 아래에서 오른쪽으로 줄어든다
매 초        숫자       살짝 튀어 오르며 나타난다
5.30~5.70s  공개       크로스페이드, 정답이 조금 컸다가 제자리로
5.70~10.6s  여운       다시 아주 천천히 당긴다 — 안 그러면 뒤 2초가 죽는다
```

확대 폭은 넉넉히 준다. 0.09로 했더니 프레임 차이가 0인 구간이 생겨 정지 화면처럼
보였다. 지금은 네 영상 모두 프레임 간 평균 변화가 0.19를 넘는다.

확대하면 가장자리가 잘린다. 그냥 확대했더니 카드 왼쪽이 화면 밖으로 밀려나
깨져 보였다. 최대 배율만큼 미리 줄여 둘레에 여백을 두고, 확대가 그 여백을
먹게 한다. 다 확대됐을 때 딱 맞는다.

소리도 음원을 받지 않고 파형을 직접 합성한다. 저작권 문제가 원천적으로 없다.
넷 다 같은 소리를 쓴다.

```
0.05s   딸깍!      고음 트랜지언트 + 낮은 몸통을 55ms 간격으로 둘
0.8s~   째깍째깍   0.5초 간격, 높낮이 번갈아, 끝 3번은 세게
5.5s    또로롱     A5·C#6·E6·A6 아르페지오 — 이때 정답이 공개된다
```

필요한 것: `ffmpeg`, 크롬 계열 브라우저. 자막은 윈도우 맑은 고딕(`malgunbd.ttf`)을 쓴다.
다른 OS에서 돌리려면 `scripts/shorts-gen.mjs`의 `FONT_B`·`FONT_R`를 그 OS의 한글 폰트로 바꿔야 한다.

**올릴 때**

- 인스타 릴스 — 올리면서 음악을 고른다. 인기 음원을 쓰면 도달에 유리하다.
  원본 소리(째깍)와 음악의 볼륨 비율은 릴스 편집기에서 조절된다
- 유튜브 쇼츠 — 그대로 올리고, 필요하면 Studio → 오디오 보관함에서 트랙을 얹는다

영상에 음악을 박아 넣지 않는 이유: 플랫폼 음원 기능을 못 쓰게 되고 저작권 클레임 위험만 생긴다.

## images

프로덕트 등록이나 SNS 첨부에 쓴다. 프로덕션 화면을 모바일 뷰포트(400×860)로 찍은 것이다.

| 파일 | 화면 |
|---|---|
| `딸깍-모바일홈.png` | 홈 (히어로 + CTA + 맛보기) |
| `딸깍-데스크톱홈.png` | 홈 (1440×900) |
| `딸깍-전개도문제.png` | 전개도 + 주사위 4지선다 |
| `딸깍-발견형.png` | 무한 연습 발견형 |
| `딸깍-발견형힌트.png` | 힌트가 열린 상태 |
| `딸깍-성냥개비.png` | 초록 LCD 전광판 |
| `딸깍-아카이브.png` | 지난 문제 목록 |

아이콘과 공유 카드는 여기 두지 않는다 — `static/icon-192.png`, `static/icon-512.png`,
`static/og-default.png`가 원본이다. 공유 카드는 `node scripts/og-gen.mjs`로 다시 만든다.

문제 화면은 문제은행에서 무작위로 나오므로 다시 찍으면 다른 문제가 나온다.
