# 딸깍 스레드 첫 주 (7일치)

계정: threads.com — 인스타그램 계정으로 바로 로그인된다.

## 올리는 법

- 하루 **한 개**. 아침 8시대 또는 저녁 9시대가 반응이 좋다
- **링크는 본문에 넣는다.** Mosseri가 링크 포함 글이 텍스트만 있는 글보다 17% 더 잘 나온다고 밝혔다.
  (인스타의 "링크 넣으면 도달 깎인다"는 스레드엔 해당하지 않는다)
- **"댓글 달아주세요" 같은 말은 쓰지 않는다.** 메타가 engagement bait를 적극 강등한다.
  문제를 던지면 사람들은 알아서 답을 단다
- 첫 두 줄만 보이고 접힌다. **거기에 문제를 걸어라.** "제가 만든 사이트인데요"가 먼저 오면 광고로 보고 넘긴다
- 댓글이 오면 답글을 단다. Mosseri가 "답글의 합은 게시물의 합만큼 가치 있다"고 했다
- 문제 글은 답을 다음 날 공개한다. 그래야 다시 온다

## 1일차 — 소개 (게시 완료 8/4)

```
매일 두뇌 퍼즐 10문제 푸는 사이트를 만들었습니다.

자정에 새로 열리고, 그날은 모두가 같은 문제를 풉니다.
5분에서 10분이면 끝납니다.

가입 없고, 설치 없고, 광고 보여주려고 문제를 잘게 쪼개지 않습니다.
들어와서 그냥 풀면 됩니다.

혼자 만들었고 이제 막 열었습니다.
오늘 문제 한번 풀어봐 주세요.
```

결과: 유입 3명, 참여 0. 소개글이라 반응이 붙을 구조가 아니었다.

## 3일차 — 정답 + 새 문제

```
어제 수열 정답입니다.

1, 10, 11, 100, 101, 110

이진법으로 센 1부터 6까지였습니다.

오늘 건 좀 다릅니다. ★가 무슨 뜻인지 찾아보세요.

9 ★ 6 = 15
4 ★ 7 = 3
15 ★ 8 = 23
3 ★ 10 = 13
12 ★ 5 = ?

이런 걸 '발견형'이라고 부르면서 매일 3문제씩 내고 있습니다.
규칙을 안 알려주고 예시만 주는 유형이에요 → ddalkkak.app
```

(답: 7 — 앞의 수가 홀수면 더하고, 짝수면 뺀 절댓값)

## 4일차 — 성냥개비

```
성냥 하나만 옮겨서 이 식을 참으로 만들어보세요.

5 + 7 = 2

부러뜨리거나 빼면 안 됩니다.
하나를 집어서 다른 자리에 놓는 것만 됩니다.

이런 문제가 741개 있는데 전부 프로그램이 만들고 프로그램이 검증했습니다.
답이 하나뿐이라는 것도 코드가 보증해요.

→ ddalkkak.app/matchstick
```

(답: **9 − 7 = 2** — `+`의 세로획 하나를 빼면 `−`가 되고, 그 획을 `5`의 오른쪽 위에 붙이면 `9`가 된다)

## 5일차 — 전개도 버그 이야기

```
전개도를 접으면 어떤 주사위가 되는지 맞히는 문제를 만들었는데,
정답이 전부 뒤집혀 있었습니다.

종이를 접으면 상자가 종이 반대편에 생기잖아요.
그런데 저는 코드에서 주사위를 종이 위에 굴렸습니다.
거울에 비친 것처럼 좌우가 통째로 바뀐 겁니다.

눈으로는 못 잡습니다. 머릿속으로 전개도 접는 건 사람이 제일 못하는 일이니까요.

한 분이 "안쪽으로 접냐 바깥쪽으로 접냐에 따라 다른 거 아니냐"고 물어봐서 알았습니다.
그 말 자체는 틀렸는데, 제가 틀린 지점을 정확히 가리키고 있었어요.

지금은 틀리면 실제로 접히는 과정을 3D로 보여줍니다.

→ ddalkkak.app/cubenet
```

이미지 첨부: `딸깍-전개도문제.png`

## 6일차 — 발견형

```
국물 → [궁물]
닫는 → [단는]
입는 → [임는]
앞문 → ?

적힌 대로가 아니라 소리 나는 대로 옮겨 적은 겁니다.
우리가 매일 무의식적으로 하고 있는데, 막상 규칙으로 적어보라면 잘 안 나와요.

이런 문제를 303개 모아뒀습니다.
막히면 힌트가 시간차로 3단계 열리고, 바로 답은 못 봅니다.

→ ddalkkak.app/discover
```

(답: [암문] — ㅁ·ㄴ 앞에서 받침이 같은 자리 콧소리로 바뀐다. ㄱ→ㅇ, ㄷ→ㄴ, ㅂ→ㅁ. 앞의 ㅍ은 ㅂ 소리라 ㅁ으로)
