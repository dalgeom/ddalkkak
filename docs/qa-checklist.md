# 딸깍 점검 기준 — 화면을 바꾸면 완료 보고 전에 전부

사용자는 검수자가 아니다. 아래를 내가 먼저 확인하고 나서 「완료」라고 말한다.
2026-10-14 하루에 사용자가 먼저 찾아낸 것: 구역 0px로 붙음(57화면) · 카드 속 카드 · 시트 ✕ 버튼 · 시트 끌어 닫기 없음 ·
닫을 때 검은 깜빡임 · 하단 탭이 아이폰 홈 바에 걸림 · 메인 돌아올 때마다 스플래시 · 새 소식이 닫아도 다시 뜸.
이 목록의 항목 하나하나가 그 실수에서 나왔다.

## 1. 자동 점검 — `npm run qa`

| 시험 | 무엇 |
|---|---|
| sweep | 사이트맵 전 화면 + 사이트맵 밖 화면을 390 · 320px로. 콘솔 오류 · HTTP 오류 · 가로 넘침 · 깨진 이미지 · 내부 링크 응답 |
| gaps | 테두리 · 배경 있는 상자끼리 세로 간격. 8px 미만(붙음) · 40px 초과(여백 겹침) |
| flow | 처음 온 사람으로 데일리 10문제 → 결과, 재방문 새 소식, /play 필터, 상식 접기 · 견본, 전개도 · 성냥 · 그림 퍼즐 · 초성, 오늘 다시 보기, 기록, 탭 이동(37개) |
| sheet | 실제 터치로 시트 끌기 · 튕기기 · 커지기 · 바깥 · 뒤로가기 · Esc, ✕ 없음, 닫을 때 막이 투명해진 뒤 지워짐, 홈 바(34px) 위 하단 탭, 스플래시 첫 1회 |
| lock | 시트 열린 동안 뒤 화면 스크롤 잠금, 닫으면 풀림 |
| webkit | 아이폰 엔진: 닫을 때 깜빡임, 스플래시, 아이폰 SE · 13 가로 넘침 |

- 운영 숫자 오염 없음: GA · 광고는 막고 /api/stat · /api/push · /api/feedback은 가로챈다.
- 로컬 먼저: `npx vite dev --port 5231` 띄우고 `QA_BASE=http://localhost:5231 npm run qa`. 배포 뒤 운영에서 한 번 더.
- 새 기능을 만들면 그 기능의 시험을 여기에 더한다(시험이 없는 기능은 끝난 게 아니다).

## 2. 눈으로 — 자동으로 못 잡는 것

**휴대폰 기본 동작**
- 아래에서 올라오는 것은 `BottomSheet` 하나로. 닫기는 끌어 내리기 · 바깥 · 뒤로가기. ✕ 버튼 두지 않는다
- 화면 아래 고정된 것(탭 · 토스트 · 버튼)은 홈 바 위(`env(safe-area-inset-bottom)`, `--tab-h`). 토스트가 탭에 가리거나 덮지 않는지
- `backdrop-filter`(흐림) 쓰지 않는다 — 사파리에서 검게 번쩍인다
- 같은 동작을 두 번 · 세 번 해 본다(메인 ↔ 다른 화면 왕복, 열고 닫기 반복, 새로고침, 다시 방문)
- 처음 온 사람 · 다시 온 사람 · 오늘 이미 푼 사람, 세 상태로 본다
- 입력: 한글 IME, 휴대폰 키보드가 올라왔을 때 가리는 것

**모양**
- 카드 속 카드 없음, 구역 사이 여백 일정(구역 26px)
- 알약 모양(999px) 칩 · 배지 쓰지 않는다, 밑줄 탭 쓰지 않는다
- 잘림 · 줄바꿈 어색함 · 320px에서 버튼 글자 넘침
- 아이콘만 있는 버튼은 무엇인지 알 수 있는지(필요하면 글자)

**문구**
- 존댓말 문장, 「~없음 — ~확인」 같은 개조식 · 줄표 금지
- 화면 부가설명(「이 자리에 ~가 나옵니다」) 넣지 않는다
- 같은 곳으로 가는 버튼은 같은 이름(「오늘의 10문제」 · 「○○ 바로 풀기」 · 「무한 연습」)

**들어가는 길**
- 새 기능은 메인 · 놀이 · 관련 화면에서 닿는지, 새 소식에 올렸는지, 계측(ga-yesterday.py 줄)이 있는지
- 보고에 「메인 → … → 새 기능」 경로를 적는다

**개인정보**
- 서버로 새로 보내는 것이 생기면 개인정보처리방침을 같이 고친다
