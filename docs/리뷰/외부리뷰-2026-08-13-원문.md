5. QWERTY 윗줄 ×3 — `top-row`, `word-keyboard`, `rc-club-toprow`.
6. 영단어 글자 수 ×3 — `honest-number`, `rc-chain-len`, `month-letters`. rc-chain-len은 반려 사유와 동일한 메커니즘의 신작.

9. `disc-4` ↔ `glyph-ascdesc` — ascender/descender ×2.

## 2. 구조·시스템 심사 — 총평 4/10

"결정론이라는 불변식을 지키기 위해 코드 자체를 역사 기록물로 동결하는 구조를 선택했고, 그 대가를 아직 다 치르지 않았다. 같은 사고가 반복된 근본 원인은 알고리즘이 아니라 검증 인프라의 부재인데, 오늘 또 알고리즘(v2)을 얹는 쪽을 택했다."

### 시한폭탄 (심각도순)
1. **[치명] 코드가 곧 DB** — v2 출력이 6개의 동결된 역사적 사실의 함수. 한 줄 리팩토링이 전 날짜 소급 재편. 이를 봉인하는 골든 스냅샷 테스트가 없음(pickStable.test는 성질 검증만 — 알고리즘을 갈아치워도 통과하면서 이력이 바뀌는 경로가 열려 있음). 컷오버 회피 로직은 8/29 이후 죽은 코드지만 영원히 삭제 불가 — 이런 층이 계속 쌓이는 구조.
2. **[치명] bankHistory 수동 부기 + 배포 타이밍 결합** — fromDay가 미래인지 테스트 불가. 배포 실패 후 재배포 시나리오에서 낮 세트 변경 재발 가능. 런타임 가드 0, 카나리 0. "교체 정책은 아카이브 소급 변조의 공식 허용."
3. **[치명, 수리비 최저] 테스트 스위트가 이미 죽어 있음** — vitest 설정 없음 → 워크트리 436개 테스트 흡수, 238 파일 fail이 "정상". CI 없음. 워크트리 40개(727MB)·브랜치 239개가 OneDrive 동기화 폴더 안. **설정 3줄이면 고침.**
4. **[높음] fieldOfChip 폴백** — 오타 chip이 조용히 관찰·추리로. 관련 테스트는 폴백 때문에 실패 불가능한 tautology. v2 레인 키가 field라 오타 하나가 레인 구성을 조용히 바꿈.
5. **[높음] 콘텐츠 중복 감지 0** — id 유니크만 검사. 정답 교집합+chip, trigram 유사도 등 기계 검사 전무.
6. **[중간] forward-simulation 성능 시효** — O(경과일×은행), cursorAt O(2만) 반복. 1년 뒤 아카이브 페이지당 수백만 연산, Workers CPU 과금 환경. 메모이제이션 없음.
7. **[중간] 콘텐츠가 코드** — problems.ts 5,842줄/305KB. 릴리스 주기 결합. 클라이언트가 오늘 10문제(수 KB)를 위해 96KB gzip 전체 은행 다운로드.
8. **[중간] localStorage 단일 저장소** — iOS ITP 7일 삭제, 기기 변경 증발. persist() 미요청, 내보내기 없음. "백엔드 없음은 제약이 아니라 선택" — Pages Functions+KV 익명 동기화 코드 가능.
9. **[중간] +page.svelte 2,569줄** — 4종 게임 엔진+랜딩+맛보기 한 파일, 상태 변수 ~40개, 암묵 상태 머신.
10. **[낮음] 자정 경계 잔여 구멍** — 자정 넘긴 홈의 낡은 서버 sample이 오늘 문제와 겹칠 수 있는 스포일러 경로. 캐시 헤더 미명시.

### 로드맵
1. [1시간] vitest include 스코프 + Pages 빌드 커맨드 `npm test && npm run build` 게이트. 워크트리·브랜치 정리, 저장소 OneDrive 밖 이전 검토.

## 3. 제품·UX 심사 — 총평 3.5/10

"콘텐츠 공장은 지어놓고 가게 입구를 골목 안에 낸 제품. 완주한 사람조차 돌아오지 않는다. 부품(이모지 마크, 스트릭, 잔디, 공유카드 gridRows)이 다 있는데 조립이 안 돼 있거나 꺼져 있다."

### 치명 결함 톱5
1. **공유 이모지 그리드가 꺼져 있음** — MARK_EMOJI·gridRows 구현 완료 상태에서 호출부가 `emojiRow: ''`. 텍스트 공유에 그리드·문제번호 없음. "이미 만들어둔 부품을 켜기만 하면 되는 결함이라 더 치명적."
2. **재방문 트리거 0개** — 코드 주석의 자백: "설치가 사실상 유일한 재방문 경로다." PWA 설치 전환율 1% 미만 × 15명 = 기대 0.1명/일. 푸시·이메일·캘린더 전무.
3. **랜딩이 브로셔** — 첫 화면에 퍼즐이 없음. 맛보기는 스크롤 아래. 첫 방문자에게 카운트다운은 혼란. 일 15명에 랜딩 광고 2개는 수익 0에 신뢰 비용만.
4. **10문제 코스 요리 강제** — 장르 표준은 1퍼즐 3분. 유형 선호가 갈리고 몰입 문법이 4번 바뀜. 제안: 코어 1문제(발견형)=스트릭, 나머지 9문제는 확장 스테이지.
5. **기록이 기기에 갇힘** — 스트릭 증발 경로 다수. 내보내기/가져오기 필요. 마일스톤 배지·프리즈·아카이브 도장 등 장르 표준 수집 장치 전무. 아카이브 29일이 전부 동일하게 생겨 클릭 이유 없음.

### 재방문 루프 재설계 4고리
① 내일의 갈고리(내일 예고 티저, .ics 캘린더, 마일스톤 예고) ② 공유를 도전장으로(이모지 그리드 + `/?challenge=` URL 인코딩 1:1 대결 — 백엔드 0) ③ 아카이브 수집판(도장·진행률 바·주간 리포트 카드) ④ 경량 백엔드(Workers KV 카운터 2개: 문제별 정답률·점수 percentile → "내 8/10이 잘한 건가"에 답 + web-push).

### 6개월 로드맵
M1 루프 응급수술(그리드 켜기·랜딩=게임·광고 제거·코어1+확장9) → M2 내일의 갈고리(티저·ics·배지·도장판·내보내기) → M3 경량 백엔드(KV 정답률·percentile·푸시·챌린지) → M4 유통 자동화(매일 문제 이미지 자동 포스팅, 아카이브 SEO 개방) → M5 시그니처 확립(발견형을 브랜드 게임으로 독립) → M6 커뮤니티(주간 리더보드·뉴스레터·제보 코너).

"앞으로 6개월간 문제를 한 개도 더 만들지 말고 루프와 유통에만 투자해도 된다."

### 핵심 판정
- SEO 가설은 맞고 키워드가 틀림: '브레인 티저'는 한국어 검색어가 아님. 실제 시장: 넌센스 퀴즈·상식 퀴즈·성냥개비 퀴즈·수수께끼·치매 예방 두뇌 게임(시니어, 미개척). 네이버 키워드도구로 실측하라(30분, 무료).
- K-팩터 0의 3요소: 유입 자체가 소수 / 공유물에 도발 없음(비교 기준 부재) / 수신자에게 10문제는 부담(1문제 단독 URL 필요).

## 5. 애드센스·수익화 심사

### 재심사 통과 확률: 45% (구간 35~55%)
갖춘 것: about·연락처·privacy(AdSense 고지)·terms·ads.txt·읽을거리 5편(1,200~1,500단어, 자체 SVG 도판, AI 슬롭 아님 — 강점)·2,191문제.
약점: **읽을거리 5편 전부 발행일 2026-08-10**(심사용 몰아넣기 패턴 그대로 노출) / sitemap 82 URL 중 아카이브 동일 템플릿 29개(35%) / byline·운영자 정체성 0 / 일 10~20 트래픽.
"심사 대기 중에도 새 날짜로 글 1~2편 추가 발행이 유일한 승률 상승 수단."

### 반려 대비 체크리스트
① 주 1~2편×4주 발행 이력 → 누적 12~15편 후 재신청(간격 2~4주) ② 아카이브: 날짜별 고유 서문 또는 sitemap 제외+noindex ③ byline+운영자 소개 ④ trivia 카테고리 16페이지 서문 300자+ ⑤ Search Console 색인율 실측 ⑥ 최후엔 트래픽으로 증명(일 100+).

### 광고 배치
플레이 라우트 무광고 원칙 유지(잘한 것). 1순위 인벤토리는 **완주(결과) 화면** — 현재 슬롯 목록에 없음. 2순위 읽을거리·가이드·trivia in-article. 글로벌 하단 배너는 모바일 오클릭 리스크 재검토. 자동광고 앵커·전면은 플레이 라우트 제외 필수. 페이지당 1~2유닛 상한. 소규모에서 지인 클릭은 ad serving limit 직행 경고.

### 월 5만원 로드맵
전제: 페이지 RPM ₩1,000~2,000, 방문당 2.5PV → **월 5만원 = 일 방문 330~670명 (현재의 22~44배)**. 현재 규모 기대 수익 월 ~₩1,700. 일 100명: 3~6개월(글 20편+). 일 330~500명: 12~18개월, 단 재방문율 개선이 전제 — "재방문이 이대로면 새는 양동이라 기간표 자체가 성립하지 않는다."

### 다각화 우선순위
① 애드센스는 '인프라'로(12개월 기대 월 수천원~1만원) ② 쿠팡파트너스는 커머스 의도 글 안에서만(조건부) ③ 후원 링크는 비용 0이니 구석에 ④ 프리미엄은 DAU 500 전 논의 금지 ⑤ 의외의 루트: **B2B 라이선스**(검증된 한국어 퍼즐 2,191문 + 검증 파이프라인은 사보·교육 앱·커뮤니티 이벤트에 단가가 더 높다. 아웃바운드 필요).

### 목표 재설정
"애드센스 월 5~10만원은 지금 단계의 목표로 틀렸다 — 12~18개월 뒤의 후행 지표다. 지금 병목은 재방문 2명이다."
대체 목표: 90일 내 재방문율 10→30%, 일 방문 100. 발행 주 1~2편 검색어 정조준. 애드센스는 승인+저밀도 배치까지만 하고 잊을 것.
