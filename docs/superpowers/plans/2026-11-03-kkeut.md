# 끝말잇기 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/kkeut`에 「오늘의 끝말잇기 퍼즐」과 「컴퓨터와 대결(5단계)」을, `/kkeut/answer/[날짜]`에 지난 퍼즐 해설을 연다.

**Architecture:** 사전(한국어기초사전 명사 27,831개)은 빌드 스크립트가 `static/kkeut/`에 JSON으로 굽고, 화면은 `/kkeut`에서만 그 파일을 받는다.
규칙 · 이기는 글자 표 · 컴퓨터 수 고르기는 순수 함수(`src/lib/kkeut.ts`), 한 판의 진행은 상태 함수(`src/lib/kkeutGame.ts`)로 나눠 vitest로 시험한다.
퍼즐은 손으로 고른 목록(`src/lib/data/kkeutPuzzles.ts`)을 날짜 번호로 꺼내고, 해설 쪽은 빌드 때 미리 굽는다(사이트 전체가 `prerender = true`).

**Tech Stack:** SvelteKit · Svelte 5(runes) · TypeScript · vitest · vite-node · Cloudflare Pages(main 푸시 = 배포)

**설계 문서:** `docs/superpowers/specs/2026-11-03-kkeut-design.md`

## 계획을 쓰며 정한 것 (설계와 다른 점)

1. **힌트는 「끝 글자」다.** 설계의 「첫 글자」는 규칙상 이미 정해져 있어 힌트가 못 된다(시작 단어의 끝 글자 또는 두음).
2. **sitemap에는 `/kkeut/answer/[날짜]`만 넣는다.** `/kkeut`는 게임 화면이라 sitemap 규칙(「게임 화면은 색인 자산이 아니다」, `src/routes/sitemap.xml/+server.ts` 머리 주석)에 따라 뺀다.
3. **11/16까지 메인 · 초성 화면에 끝말잇기 링크를 달지 않는다.** `GameCards`는 메인 「놀이 고르기」에도 쓰이고 `OtherGames`는 초성 화면 맨 아래에 붙는다.
   11/9~16 초성 착지 판정이 섞이지 않게, 카드는 `/games`(`full`)에서만 보이고 `OtherGames` · 새 소식(`notices.ts`)은 11/17에 단다(Task 11).
4. **뜻풀이는 초성별 조각 19개로 나눈다**(`static/kkeut/defs/0.json`~`18.json`). 판 끝에 그 판에 나온 말의 조각만 받는다.
5. **카드 숫자 단위는 「낱말」**이다. `GameCards`에 `unit` 필드를 더하고, 없으면 「문제」로 둔다.

```ts
/**
 * 끝말잇기(2026-11-03) — 두음 · 받는 말 판정 · 이기는 글자 표 · 컴퓨터 수 고르기.
 * 사전은 한국어기초사전(국립국어원, CC BY-SA 2.0 KR) 명사 — scripts/kkeut-build.mjs가 static/kkeut/에 굽는다.
 * 설계: docs/superpowers/specs/2026-11-03-kkeut-design.md
 */
const BASE = 0xac00;
/** 중성 ㅑ ㅕ ㅖ ㅛ ㅠ ㅣ */
const Y = new Set([2, 6, 7, 12, 17, 20]);

/** 두음법칙으로 대신 시작해도 되는 글자, 없으면 null */
export function dueum(c: string): string | null {
	const o = c.charCodeAt(0) - BASE;
	if (o < 0 || o > 11171) return null;
	let cho = Math.floor(o / 588);
	const jung = Math.floor((o % 588) / 28);
	const jong = o % 28;
	if (cho === 5) cho = Y.has(jung) ? 11 : 2;
	else if (cho === 2 && Y.has(jung)) cho = 11;
	else return null;
	return String.fromCharCode(BASE + cho * 588 + jung * 28 + jong);
}

/** 끝 글자 c 다음에 시작할 수 있는 글자들 */
export function startsFor(c: string): string[] {
	const d = dueum(c);
	return d ? [c, d] : [c];
}

export const last = (w: string) => w[w.length - 1];

export type Dict = { words: string[]; easy: Set<string>; has: Set<string>; byFirst: Map<string, string[]> };

export function makeDict(words: string[], easy: string[] = []): Dict {
	const byFirst = new Map<string, string[]>();
	for (const w of words) {
		const a = byFirst.get(w[0]);
		if (a) a.push(w);
		else byFirst.set(w[0], [w]);
	}
	return { words, easy: new Set(easy), has: new Set(words), byFirst };
}

/** c로 끝난 말 다음에 낼 수 있는 말(이미 나온 말은 뺀다) */
export function movesFrom(d: Dict, c: string, used: Set<string> = new Set()): string[] {
	const out: string[] = [];
	for (const s of startsFor(c)) for (const w of d.byFirst.get(s) ?? []) if (!used.has(w)) out.push(w);
	return out;
}

export type Reject = 'short' | 'first' | 'notword' | 'used';

export function check(
	d: Dict,
	prev: string | null,
	raw: string,
	used: Set<string>
): { ok: true; word: string } | { ok: false; why: Reject } {
	const word = raw.replace(/\s+/g, '');
	if (word.length < 2) return { ok: false, why: 'short' };
	if (prev && !startsFor(last(prev)).includes(word[0])) return { ok: false, why: 'first' };
	if (!d.has.has(word)) return { ok: false, why: 'notword' };
	if (used.has(word)) return { ok: false, why: 'used' };
	return { ok: true, word };
}
```

```ts
import type { Tier } from '$lib/tiers';

/**
 * 글자 단위 역행 분석(다시 쓰기 금지는 무시한다).
 * win: 그 글자 차례인 쪽이 반드시 이기는 데 드는 내 수, lose: 반드시 지기까지 남은 상대 수(0 = 이을 말이 없음).
 * 둘 다 없는 글자는 어느 쪽도 반드시 이기지 못한다(사전 전체로 188종).
 */
export type Table = { win: Map<string, number>; lose: Map<string, number> };

export function charTable(d: Dict, maxDepth = 8): Table {
	const chars = new Set<string>();
	for (const w of d.words) {
		chars.add(w[0]);
		chars.add(last(w));
	}
	const next = new Map<string, string[]>();
	for (const c of chars) next.set(c, [...new Set(movesFrom(d, c).map(last))]);
	const win = new Map<string, number>();
	const lose = new Map<string, number>();
	for (const c of chars) if (!next.get(c)!.length) lose.set(c, 0);
	for (let depth = 1; depth <= maxDepth; depth++) {
		let changed = false;
		for (const c of chars) {
			if (win.has(c) || lose.has(c)) continue;
			if (next.get(c)!.some((e) => (lose.get(e) ?? 99) < depth)) {
				win.set(c, depth);
				changed = true;
			}
		}
		for (const c of chars) {
			if (win.has(c) || lose.has(c)) continue;
			if (next.get(c)!.every((e) => (win.get(e) ?? 99) <= depth)) {
				lose.set(c, depth);
				changed = true;
			}
		}
		if (!changed) break;
	}
	return { win, lose };
}

const pick = <T>(a: T[], rand: () => number) => a[Math.floor(rand() * a.length)];

/** 상대가 반드시 지는 글자로(빨리 지는 쪽 먼저), 없으면 미정 글자로, 그것도 없으면 가장 오래 버티는 쪽으로 */
export function best(t: Table, ms: string[], rand: () => number = Math.random): string {
	const score = (w: string) => {
		const e = last(w);
		const l = t.lose.get(e);
		if (l !== undefined) return 1000 - l;
		return t.win.get(e) ?? 500;
	};
	const top = Math.max(...ms.map(score));
	return pick(
		ms.filter((w) => score(w) === top),
		rand
	);
}

/**
 * 단계별 컴퓨터 수(tiers.ts 1 새싹 ~ 5 고수).
 * 새싹 · 쉬움은 쉬운 말(초급 · 중급)만 안다. 새싹은 한방을 피하고, 어려움은 한방이 있으면 내고, 고수는 표대로 최선.
 */
export function pickMove(
	d: Dict,
	t: Table,
	tier: Tier,
	c: string,
	used: Set<string>,
	rand: () => number = Math.random
): string | null {
	let ms = movesFrom(d, c, used);
	if (tier <= 2) ms = ms.filter((w) => d.easy.has(w));
	if (!ms.length) return null;
	const dead = (w: string) => t.lose.get(last(w)) === 0;
	if (tier === 1) {
		const soft = ms.filter((w) => !dead(w));
		return pick(soft.length ? soft : ms, rand);
	}
	if (tier === 4) {
		const k = ms.filter(dead);
		return pick(k.length ? k : ms, rand);
	}
	if (tier === 5) return best(t, ms, rand);
	return pick(ms, rand);
}

/** 오늘의 퍼즐 수: 월~목 1 · 금 2 · 토 · 일 3 (day = kstDayNumber, 0일은 1970-01-01 목요일) */
export function puzzleMoves(day: number): 1 | 2 | 3 {
	const wd = (day + 4) % 7; // 0 = 일요일
	if (wd === 5) return 2;
	if (wd === 6 || wd === 0) return 3;
	return 1;
}

/**
 * 다시 쓰기 금지까지 넣어 w를 내면 k수 안에 반드시 이기나 — 빌드 검증용이다. 화면에서는 부르지 않는다(3수면 수 초).
 * t를 주면 표로 가망 없는 수를 건너뛴다(이긴다고 답한 것은 언제나 참이고, 못 찾은 퍼즐은 버리면 된다).
 */
export function winsWith(d: Dict, w: string, k: number, used: Set<string>, t?: Table): boolean {
	used.add(w);
	let all = true;
	for (const r of movesFrom(d, last(w), used)) {
		used.add(r);
		const ok = k > 1 && forcedWin(d, last(r), k - 1, used, t) !== null;
		used.delete(r);
		if (!ok) {
			all = false;
			break;
		}
	}
	used.delete(w);
	return all;
}

/** c 차례인 쪽이 k수 안에 반드시 이기는 첫 수, 없으면 null */
export function forcedWin(d: Dict, c: string, k: number, used: Set<string>, t?: Table): string | null {
	if (k <= 0) return null;
	for (const w of movesFrom(d, c, used)) {
		if (t && (t.lose.get(last(w)) ?? 99) > k - 1) continue;
		if (winsWith(d, w, k, used, t)) return w;
	}
	return null;
}
```

```ts
import type { Tier } from '$lib/tiers';
import { best, check, last, movesFrom, pickMove, type Dict, type Reject, type Table } from './kkeut';

/**
 * 끝말잇기 한 판(2026-11-03). 화면(/kkeut)은 이 상태를 그리기만 한다.
 * 퍼즐: 컴퓨터는 사전 전체로 최선(best). N번째 사람 말 뒤에도 받아치면 실패.
 * 대결: 단계별 pickMove. 무승부 글자가 188종이라 사람이 DUEL_LIMIT수를 버티면 사람 승리로 끝낸다.
 */
export const DUEL_LIMIT = 20;

export type Turn = { who: 'me' | 'cpu'; word: string };
export type Game = {
	mode: 'puzzle' | 'duel';
	tier: Tier;
	n: number;
	chain: Turn[];
	used: Set<string>;
	end: null | 'win' | 'lose' | 'fail' | 'giveup';
};

const make = (mode: Game['mode'], tier: Tier, n: number, start: string): Game => ({
	mode,
	tier,
	n,
	chain: [{ who: 'cpu', word: start }],
	used: new Set([start]),
	end: null
});

export const newPuzzle = (start: string, n: number) => make('puzzle', 5, n, start);
export const newDuel = (tier: Tier, start: string) => make('duel', tier, 0, start);

/** 대결 첫 단어 — 쉬운 말 중 사람이 처음부터 지지 않고, 이을 말이 다섯 개 넘는 글자로 끝나는 것 */
export function firstWord(d: Dict, t: Table, tier: Tier, rand: () => number = Math.random): string {
	const ok = (w: string) => !t.lose.has(last(w)) && movesFrom(d, last(w)).filter((x) => tier > 2 || d.easy.has(x)).length > 5;
	const pool = d.words.filter((w) => d.easy.has(w) && ok(w));
	const from = pool.length ? pool : d.words.filter((w) => !t.lose.has(last(w)));
	return from[Math.floor(rand() * from.length)];
}

/** 사람 한 수. 받지 않으면 이유를, 받으면 null(컴퓨터 답 · 판 끝은 g에 적힌다) */
export function play(g: Game, d: Dict, t: Table, raw: string, rand: () => number = Math.random): Reject | null {
	if (g.end) return null;
	const r = check(d, g.chain[g.chain.length - 1].word, raw, g.used);
	if (!r.ok) return r.why;
	g.chain.push({ who: 'me', word: r.word });
	g.used.add(r.word);
	const mine = g.chain.filter((x) => x.who === 'me').length;
	if (g.mode === 'duel' && mine >= DUEL_LIMIT) {
		g.end = 'win';
		return null;
	}
	const ms = movesFrom(d, last(r.word), g.used);
	const reply = g.mode === 'puzzle' ? (ms.length ? best(t, ms, rand) : null) : pickMove(d, t, g.tier, last(r.word), g.used, rand);
	if (!reply) {
		g.end = 'win';
		return null;
	}
	g.chain.push({ who: 'cpu', word: reply });
	g.used.add(reply);
	const stuck = !movesFrom(d, last(reply), g.used).length;
	if (g.mode === 'puzzle' && (mine >= g.n || stuck)) g.end = 'fail';
	else if (stuck) g.end = 'lose';
	return null;
}

/** 「모르겠어요」 — 판을 끝내고 낼 수 있었던 말을 셋까지(쉬운 말 먼저) */
export function giveUp(g: Game, d: Dict): string[] {
	g.end = 'giveup';
	const ms = movesFrom(d, last(g.chain[g.chain.length - 1].word), g.used);
	return [...ms.filter((w) => d.easy.has(w)), ...ms.filter((w) => !d.easy.has(w))].slice(0, 3);
}
```

```ts
 * line = 정답 길 하나: 사람 · 컴퓨터 · 사람 … (마지막 사람 말 뒤에 컴퓨터가 이을 말이 없다). 해설 쪽이 이 길을 보여 준다.
 * 판정은 line과 대조하지 않는다 — 다른 길로 막아도 성공이다(kkeutGame.ts play).
 * 공개된 날은 고치지 않는다. 고르는 기준: 정답 말을 「아는 사람이 꽤 있을 말」, 3초 룰 · 지식 조회 아님.
 * 2수 이상은 `npx vite-node scripts/kkeut-build.mjs -- --check`를 통과한 것만 넣는다.
 */
export type KkeutPuzzle = { date: string; start: string; line: string[] };

/** 2026-11-05 */
export const KKEUT_FIRST_DAY = 20762;

export const KKEUT_PUZZLES: KkeutPuzzle[] = [
	// Step 4에서 채운다
];

export function puzzleFor(day: number): KkeutPuzzle | null {
	const i = day - KKEUT_FIRST_DAY;
	return i >= 0 ? (KKEUT_PUZZLES[i] ?? null) : null;
}
```

```svelte
<script lang="ts">
	import { onMount } from 'svelte';
	import { dev } from '$app/environment';
	import { track } from '$lib/analytics';
	import { kstDayNumber } from '$lib/game';
	import { TIERS, tierName, type Tier } from '$lib/tiers';
	import { charTable, makeDict, last, type Dict, type Reject, type Table } from '$lib/kkeut';
	import { firstWord, giveUp, newDuel, newPuzzle, play, DUEL_LIMIT, type Game } from '$lib/kkeutGame';
	import { puzzleFor, type KkeutPuzzle } from '$lib/data/kkeutPuzzles';
	import { nextStreak, shownStreak, type DayStreak } from '$lib/dailyStreak';
	import { KKEUT_WORDS } from '$lib/data/kkeutMeta';

	/*
	 * 끝말잇기(2026-11-03) — 오늘의 퍼즐(N수 안에 컴퓨터 막기)과 컴퓨터 대결 5단계.
	 * 사전(static/kkeut/words.json)은 이 화면에서만 받는다. 뜻풀이는 판 끝에 그 판에 나온 말의 조각만 받는다.
	 * 설계: docs/superpowers/specs/2026-11-03-kkeut-design.md
	 */
	const DAILY_KEY = 'ddal.kkeut.daily';
	const TIER_KEY = 'ddal.kkeut.tier';
	const WHY: Record<Reject, string> = {
		short: '두 글자 이상으로 써 주세요.',
		first: '앞말의 끝 글자로 시작해야 해요.',

		used: '이미 나온 말이에요.'
	};
	const today = () => (dev && Number(new URL(location.href).searchParams.get('day'))) || kstDayNumber(Date.now());

	let dict: Dict | null = $state(null);
	let table: Table | null = null;
	let puzzle: KkeutPuzzle | null = $state(null);
	let day = $state(0);
	let streak: DayStreak | null = $state(null);

	let game: Game | null = $state(null);

	let input = $state('');
	let msg = $state('');
	let giveHints: string[] = $state([]);
	let defs: Record<string, string> = $state({});
	let field: HTMLInputElement | undefined = $state();

	const read = <T,>(k: string): T | null => {
		try {
			return JSON.parse(localStorage.getItem(k) ?? 'null');
		} catch {
			return null;
		}
	};
	const write = (k: string, v: unknown) => {
		try {
			localStorage.setItem(k, JSON.stringify(v));
		} catch {}
	};

	onMount(async () => {
		day = today();
		puzzle = puzzleFor(day);
		streak = read<DayStreak>(DAILY_KEY);
		cleared = read<number>(TIER_KEY) ?? 0;
		const j = await (await fetch('/kkeut/words.json')).json();
		dict = makeDict(j.words, j.easy);
		table = charTable(dict);
	});

	let doneToday = $derived(!!streak && streak.day === day);
	let mineCount = $derived(game ? game.chain.filter((x) => x.who === 'me').length : 0);

	function startPuzzle() {
		if (!puzzle) return;
		game = newPuzzle(puzzle.start, (puzzle.line.length + 1) / 2, puzzle.line);
		msg = '';
		track('kkeut_daily_start', { n: game.n });
		focus();
	}
	function startDuel(tier: Tier) {
		if (!dict || !table) return;
		game = newDuel(tier, firstWord(dict, table, tier));
		msg = '';
		giveHints = [];
		track('kkeut_duel_start', { tier });
		focus();
	}
	const focus = () => setTimeout(() => field?.focus(), 50);

	function submit(e: SubmitEvent) {
		e.preventDefault();
		if (!game || !dict || !table || !input.trim()) return;
		const why = play(game, dict, table, input);
		game = game; // 같은 객체 안을 바꿨으니 다시 그리게 한다
		if (why) {
			msg = WHY[why];
			return;
		}
		input = '';
		msg = '';
		if (game.end) finish();
		else focus();
	}

	function finish() {
		if (!game) return;
		const moves = mineCount;
		if (game.mode === 'puzzle') {
			if (game.end === 'win') {
				streak = nextStreak(streak, day, 'won');
				write(DAILY_KEY, streak);
				track('kkeut_daily_solve', { n: game.n, tries: tries + 1 });
			} else {
				tries++;
				if (tries >= 3) reveal();
			}
		} else {
			track(`kkeut_duel_${game.end}`, { tier: game.tier, moves });
			if (game.end === 'win' && game.tier > cleared) {
				cleared = game.tier;
				write(TIER_KEY, cleared);
			}
		}
		loadDefs(game.chain.map((x) => x.word));
	}

	function reveal() {
		streak = nextStreak(streak, day, 'revealed');
		write(DAILY_KEY, streak);
		track('kkeut_daily_reveal', { n: puzzle ? (puzzle.line.length + 1) / 2 : 0 });
		if (puzzle) loadDefs([puzzle.start, ...puzzle.line]);
	}

	function quit() {
		if (!game || !dict) return;
		giveHints = giveUp(game, dict);
		game = game;
		track('kkeut_duel_giveup', { tier: game.tier, moves: mineCount });
		loadDefs(game.chain.map((x) => x.word));
	}

	async function loadDefs(words: string[]) {
		const cho = (w: string) => Math.floor((w.charCodeAt(0) - 0xac00) / 588);
		const need = [...new Set(words.map(cho))];
		const parts = await Promise.all(need.map((n) => fetch(`/kkeut/defs/${n}.json`).then((r) => r.json())));
		const out: Record<string, string> = {};
		for (const w of words) for (const p of parts) if (p[w]) out[w] = p[w];
		defs = out;
	}

	function back() {
		game = null;
		input = '';
		msg = '';
		giveHints = [];
	}
</script>
```

```ts
import { readFileSync } from 'node:fs';
import { error } from '@sveltejs/kit';
import { kstDayNumber } from '$lib/game';
import { KKEUT_FIRST_DAY, KKEUT_PUZZLES } from '$lib/data/kkeutPuzzles';
import type { EntryGenerator } from './$types';

// 지난 오늘의 끝말잇기 해설(2026-11-03) — 오간 말과 사전 뜻을 HTML에 굽는다. 오늘 · 앞날 퍼즐은 굽지 않는다.
export const prerender = true;

const past = () => KKEUT_PUZZLES.filter((_, i) => KKEUT_FIRST_DAY + i < kstDayNumber(Date.now()));

export const entries: EntryGenerator = () => past().map((p) => ({ date: p.date }));

export function load({ params }) {
	const p = past().find((x) => x.date === params.date);
	if (!p) error(404, '없는 날이에요');
	const cho = (w: string) => Math.floor((w.charCodeAt(0) - 0xac00) / 588);
	const words = [p.start, ...p.line];
	const defs: Record<string, string> = {};
	for (const w of words) defs[w] = JSON.parse(readFileSync(`static/kkeut/defs/${cho(w)}.json`, 'utf8'))[w] ?? '';
	const i = KKEUT_PUZZLES.indexOf(p);
	return { p, defs, n: (p.line.length + 1) / 2, prev: KKEUT_PUZZLES[i - 1]?.date ?? null, next: past()[i + 1]?.date ?? null };
}
```
