## 정한 것 (사용자 선택)

| 질문 | 결정 |
|---|---|
| 입력 | 낱말 통째 입력. 열쇠를 고르고 입력창에 친다. 칸마다 한 글자씩 치면 휴대폰 한글 조합이 꼬인다. |
| 열쇠 출처 | 생성기와 사람 손질. 사전 뜻풀이를 초안으로 쓰고, 미리 풀 때 어색한 것을 고친다. |

| 만드는 법 | 미리 굽고 손질해서 날짜별 파일에 7일 앞까지 저장한다. 끝말잇기 퍼즐과 같은 방식이다. |

## 1. 화면 `/crossword`

- 위에 5×5 격자가 있다. `■`는 검은 칸이다. 낱말이 시작하는 칸 귀퉁이에 번호를 단다.
- 아래에는 지금 고른 열쇠(「가로 3. …」)와 입력창, 「넣기」 버튼이 있다.
- 칸을 누르면 그 칸이 들어 있는 낱말이 골라진다. 같은 칸을 한 번 더 누르면 가로와 세로가 바뀐다. 열쇠 목록에서 골라도 된다.
- 넣기
  - 글자 수가 낱말 길이와 같아야 들어간다. 다르면 「3글자예요」를 보여 준다.
  - 엇갈리는 칸에 다른 글자가 있으면 덮어쓴다. 종이 퍼즐과 같다.
  - 한글 완성형 글자만 받는다. 앞뒤 공백은 지운다.
- 채점
  - 모든 칸이 차면 자동으로 채점한다.
  - 틀린 칸은 빨갛게 표시한다. 고쳐서 다시 채우면 다시 채점한다.
  - 그때까지 정답은 알려 주지 않는다.
- 힌트: 「글자 하나 열기」는 고른 낱말의 빈 칸이나 틀린 칸 하나를 정답으로 채운다. 쓴 횟수를 센다.
- 결과
  - 걸린 시간, 힌트 수, 공유 문구(이모지 격자와 주소)를 보여 준다.
  - 낱말마다 사전 뜻풀이를 보여 준다. 끝말잇기와 같이 `static/kkeut/defs`를 쓴다.
  - 출처를 적는다(국립국어원 한국어기초사전, CC BY-SA 2.0 KR).
- 저장: 그날 판의 칸 상태, 시작 시각, 힌트 수를 localStorage에 둔다. 다시 오면 이어서 푼다.
- 쪽 아래 설명글: 푸는 법과 이 퍼즐을 만드는 방식. thin 시험 기준인 본문 200자 이상을 넘긴다.

## 2. 데이터와 생성기

```ts
// src/lib/data/crosswordPuzzles.ts
export type CrosswordPuzzle = {
  date: string;                   // YYYY-MM-DD (KST)
  rows: string[];                 // 5줄, 검은 칸은 '■' 예: '비공개■■'
  clues: Record<string, string>;  // 낱말 → 열쇠(손질한 문장)
};
export const CROSSWORD_FIRST_DAY: number; // 첫 날짜번호
export const CROSSWORD_PUZZLES: CrosswordPuzzle[];
```

- 낱말과 번호는 `rows`에서 코드가 뽑는다(`src/lib/crossword.ts`).
  - 가로와 세로로 2칸 이상 이어진 것이 낱말이다.
  - 번호는 위에서 아래로, 왼쪽에서 오른쪽으로 매긴다.
- 생성기 `scripts/crossword-build.mjs`
  - `--cand N`: 모양 목록을 돌려 쉬운 낱말(`words.json`의 `easy`)로 채운 후보 N개를 낸다. 낱말마다 사전 뜻풀이를 열쇠 초안으로 붙인다.
    - 한 판에 같은 낱말은 넣지 않는다.
    - 뜻풀이에 답 낱말이 그대로 들어 있으면 그 낱말은 쓰지 않는다.
    - 지난 판에 나온 낱말은 피한다.
  - `--check`: 저장된 모든 판에서 아래를 확인한다. 하나라도 걸리면 종료 코드 1을 낸다.
    - 줄 수와 칸 수
    - 낱말이 사전에 있는가
    - 모든 낱말에 열쇠가 있는가
    - 열쇠에 답 낱말이 들어 있지 않은가
    - 검은 칸 때문에 떨어진 섬이 없는가
- 테스트 `crosswordPuzzles.test.ts`
  - 퍼즐이 7일 앞까지 있다.
  - 날짜가 하루씩 이어진다.
  - `--check`와 같은 규칙을 지킨다.
  - 양성 대조로, 일부러 깨뜨린 판이 걸리는지 본다.
- 손질 기준: 열쇠는 「밖으로 내보내는 문제」 기준을 따른다.
  - 답이 문장에 드러나지 않는다.
  - 사전 투 한자어 풀이는 쉬운 말로 바꾼다.
  - 하나의 답으로 좁혀진다. 엇갈리는 글자를 함께 보면 좁혀져도 된다.
  - **안 엇갈리는 칸**(한 낱말에만 속한 칸)이 있는 낱말은 엇갈리는 글자로 좁혀지지 않는다. 시험해 보니 흰 칸의 약 38%가 이런 칸이었다. 이런 낱말은 열쇠만 보고도 답이 하나로 정해져야 한다. 미리 풀 때 따로 확인한다. 채점은 정답 격자 하나와만 비교하므로, 뜻이 비슷한 다른 낱말을 넣으면 오답이 된다.
- 첫 묶음은 **14일치**로 만든다. 「7일 앞까지」 테스트는 `Date.now()`를 기준으로 하므로, 보충이 하루만 밀려도 깨진다(끝말잇기 d4433d3). 주말에는 손대지 않는 규칙도 있다.
- 앞날 정답 보호: 운영 빌드에서 `/crossword?day=`는 오늘보다 뒤 날짜를 열지 않는다. dev 빌드에서만 앞날을 연다. `/crossword/answer/[date]`의 entries는 지난 날짜만 담는다. 테스트로 둘 다 확인하고, 일부러 앞날을 넣었을 때 빨개지는지 양성 대조를 한다.

## 3. 지난 퍼즐 `/crossword/answer/[date]`

- 지난 날짜만 미리 굽는다(`prerender`, `entries`는 지난 날짜). 오늘과 앞날 것은 굽지 않는다. 끝말잇기 해설 쪽과 같다.
- 싣는 것
  - 정답 격자
  - 낱말별 손질 열쇠와 사전 뜻풀이
  - 「이 판에서 막히기 쉬운 칸」 한 줄. 미리 풀 때 적는다. 없는 판은 이 줄을 빼고, 판마다 다른 내용을 손질 열쇠로 채운다.
- 「그날 퍼즐 풀기」 버튼(`/crossword?day=`)도 둔다. 지난 판은 운영에서도 열린다.
- 사이트 지도에 넣는다.
- 가설: 사전 뜻풀이만 옮겨 오면 얇거나 중복된 쪽으로 보일 수 있다. 그래서 손질 열쇠와 막히는 칸을 함께 싣는다.
