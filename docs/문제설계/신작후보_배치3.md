# 발견형 신작 후보 — 배치 3 (정예 15문제, 2026-07-11)

기준 1~17 전체 선적용. 목표 통과율 80%+. 25개 대신 15개 정예로 낸 이유: 신규 규칙 후보의 밀도가 낮아지는 구간이라 필러 배제 (명세 PART 8 고갈 곡선 예측대로).
채점: ✅ / ❌(+이유 한 줄). ★ 대표작 후보.

---

### 수·기호 계열

**1.** ★ `一=1, 二=2, 三=3, 四=?` → **5** ●●●
규칙: 값이 아니라 **획수** — 一二三은 획수와 값이 우연히 일치하는 완벽한 미끼, 四는 5획. 확신 높음. (보너스 반전: 五는 거꾸로 4획)
❌
이유: 좋긴한데 그냥 이렇게문제만 내면 무조건 사람들이 분노한다. 아니 당연히 이건 4지 이게 왜 획수야 이건 억지지. 라고 한다고 이걸 문제로 내려면 五=4 이거까지 문제로 나와 있어야 사람들이 머리를써서 아 이건 획수구나 라고 해서 정답은 5! 라고 기분좋고 재밌게 맞추지

**2.** `A+J=Q, Q−J=A, K−A=?` → **Q** ●●
규칙: 트럼프 순번(A=1, J=11, Q=12, K=13). 미끼: 알파벳 순번으로 풀면 A(1)+J(10)=11=K이어야 하는데 Q라서 첫 줄에서 사망. 지식 판정 요청: 트럼프 순서가 화이트리스트에 드는지 애매 — 반려 시 수용. 확신 중.
✅

**3.** `26=알파벳, 12=달, 7=요일, 24=?` → **시간(하루)** ●●
규칙: 숫자 = 익숙한 체계의 "세트 크기". 확신 중상.
✅

**4.** `0이 4개=만, 0이 8개=억, 0이 12개=?` → **조** ●●
규칙: 한국어 큰 수는 0이 4개씩 늘 때마다 이름이 바뀜 (서양의 3개 단위와 다른 체계라는 발견). 확신 중.
✅

### 영단어 계열

**5.** ★ `NET=10, TOW=2, THERE=3, EVENS=?` → **7** ●●●
규칙: 글자를 재배열하면 수 이름 (TEN, TWO, THREE, SEVEN) — 전부 진짜 영단어라 애너그램 발상이 늦게 옴. 확신 높음.
❌
이유: 애너그램 관련 문제 매우 좋긴한데, 지금 이문제는 난이도가 너무쉬움

**6.** ★ `1=ST, 2=ND, 12=TH, 22=?` → **ND** ●●●
규칙: 영어 서수 접미사(1st, 2nd) — 12=TH가 킬러 미끼(11·12·13만 예외로 TH). 22는 다시 ND(twenty-second). 확신 높음.
❌
이유: 재미없음

**7.** `TFF=보다, FHH=달걀, GPY=여우, EPH=?` → **개** ●●●
규칙: 각 글자를 알파벳 한 칸 앞으로 (SEE, EGG, FOX, DOG). 자판 시프트(배치1 통과작)의 알파벳판 — 계열 유사성이 걸리면 반려 수용. 확신 중상.
✅

**8.** `이름의 글자 수가 자기 자신과 같은 유일한 영어 수는?` → **4 (FOUR)** ●●
규칙: F-O-U-R = 4글자. 탐색형 + 유일성. 확신 중상.
✅

**9.** [선택지] `어떤 클럽: 2 ✓, 4 ✓, 6 ✓ — 그런데 8은 거절당했다. 이유는?` (짝수 클럽이 아니다!) [이름에 E가 들어가서 / 획수가 많아서 / 2의 거듭제곱이라서 / 발음이 길어서] → **이름에 E** ●●●
규칙: TWO·FOUR·SIX엔 E가 없고 EIGHT엔 있음. 짝수라는 강력한 가짜 공통점이 미끼. 확신 중상.
✅

**10.** [선택지] `알파벳의 정중앙 글자는?` [M / N / M과 N / L] → **M과 N** ●●
규칙: 26은 짝수라 정중앙이 두 개(13번째 M, 14번째 N) — "하나"라는 전제 자체가 함정. 확신 중.
❌
이유: 재미없음

**11.** `SUNDAY=해, MONDAY=달, SATURDAY=?` → **토성** ●●
규칙: 영어 요일 어원의 천체 (SUN·MOON·SATURN). 한국어 오행 문제(배포됨)의 영어 거울 — 土(흙) vs SATURN(토성) 대비가 보너스 아하. 확신 중상.
❌
이유: 재미없음 누가 sunday는 해 monday는 달인거 보고 saturday는 토성이야? 이걸 보고 재미를 느끼고 희열을 느끼냐?

### 관찰·추론 계열

**12.** `1층에서 4층까지 계단으로 30초 걸린다. 같은 속도로 1층에서 8층까지는?` → **70초** ●●●
규칙: 울타리 문제 — 4층까지는 3개 구간(구간당 10초), 8층까지는 7개 구간. 미끼: 60초(단순 2배). 확신 높음.
✅

**13.** `펼친 책의 왼쪽·오른쪽 페이지 번호를 곱했더니 600이었다. 두 페이지는?` → **24와 25** ●●
규칙: 펼친 페이지는 연속수 — √600 근처의 연속쌍. 무작정 인수분해 대신 "연속"의 발견이 지름길. 확신 중상.
✅ 이런문제 괜찮긴한데 너무 어려운 암산은 더이상 출제하면 안됨. 딱 이정도 수준의 암산까지는 ok.

**14.** `금요일에서 7,777일 뒤는 무슨 요일?` → **금요일** ●●
규칙: 7777 = 7×1111, 7의 배수라 요일 불변 — 계산이 아니라 관찰로 푸는 문제. 확신 중상.
✅

### 한글 계열

**15.** [선택지] `ㄱ·ㄷ·ㅂ·ㅅ·ㅈ, 다섯 자음만 가진 특권은?` [쌍둥이(된소리 짝)가 있다 / 이름이 한 글자다 / 받침이 될 수 있다 / 획수가 같다] → **된소리 짝** ●●
규칙: ㄲㄸㅃㅆㅉ가 존재하는 자음은 정확히 이 다섯. 확신 중.
❌
이유: 그냥 이런 객관식 문제는 너무 쉽고 재미도 없다.
