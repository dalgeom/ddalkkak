# 발견형 신작 후보 — 배치 4 (8문제, 2026-07-12)

**재미 이론 v1.0 첫 적용 배치.** 각 문제에 재미 자가 채점 5항목 표기:
[방황(가설 3개+) / 발판(유형) / 실험 / 해금(연쇄 가점) / 자존감("내가 풀었다" 높이)]
목표: 배치 3의 60% → 75%+ 회복. 정예 8개 (재제출 2 + 신작 6).

---

**1.** ★재제출 `一=1, 二=2, 五=4, 四=?` → **5** ●●
규칙: 획수. 배치 3 반려("五=4까지 나와 있어야") 처방 그대로 반영 — 五=4가 값 가설을 죽이는 반증 예시이자 발판.
재미채점: 방황 ✓(값·순서·획수) / 발판 ✓유형③ 이상치(五=4?!) / 실험 ✓(획 세어보기) / 해금 ✓연쇄(규칙 발견 → 一二三이 미끼였다는 2차 깨달음) / 자존감 ✓(초등 한자). 확신 높음.

**2.** ★재제출(하드판) — 다음 등식들이 성립한다:

```
WON + TOW = THERE
THERE + EVENS = NET

NET − EVENS − TOW = ?
```

→ **1 (WON)** ●●●
규칙: 각 단어를 재배열하면 수 이름 (ONE+TWO=THREE, THREE+SEVEN=TEN). 배치 3 "너무 쉬움" 반려의 하드판 — 등식 형태라 산술 검산이 내장.
재미채점: 방황 ✓(글자수·순번합·공통글자) / 발판 ✓유형①(THERE 속 THREE가 어느 순간 보임) / 실험 ✓(재배열) / 해금 ✓✓연쇄(애너그램 발견 → 1+2=3 산술까지 성립하는 2차 쾌감) / 자존감 ✓. 확신 중상.

**3.** ★신작·시각 — 전광판에 **부서진 파편** 같은 게 떠 있다:

```
[e·f획만 켜진 파편] + [a·d·e획만 켜진 파편] = 7    (예시1: 실체는 3+4)
[a·d·e·f·g 파편] + [완전히 꺼진 자리?!] = 9          (예시2: 실체는 1+8)
[b획 하나 파편] + [e획 하나 파편] = ?
```

→ **15** (실체 6+9) ●●●
규칙: 파편 = 진짜 숫자의 **꺼진 획들** (여집합). 8의 여집합 = 완전 공백이 결정적 발판.
재미채점: 방황 ✓(이게 글자인가? 고장인가?) / 발판 ✓✓유형③+⑤("아무것도 없는 자리가 8이라고?" + 지각 반전) / 실험 ✓(8에서 빼보기) / 해금 ✓(모든 파편이 일제히 숫자로) / 자존감 ✓. 확신 중상. ※투입 시 렌더러에 반전 모드 추가 필요.

**4.** `1:00 = 60, 1:30 = 90, 2:15 = ?` → **135** ●●
규칙: 시각을 분으로 환산.
재미채점: 방황 ✓(시+분? 시×분? 왜 1:00이 60?) / 발판 ✓유형③(1:00=60의 어색함) / 실험 ✓ / 해금 ✓ / 자존감 △(해금이 소박). 확신 중.

**5.** `카드 '68'을 거꾸로 들면 '89'가 된다. 거꾸로 들어도 자기 자신인 두 자리 수 중 가장 큰 것은?` → **96** ●●
규칙: 회전 가능 숫자(0,1,8,6↔9) 조합 탐색 — 96⟲=96.
재미채점: 방황 ✓(어떤 숫자가 돌아가지?) / 발판 ✓(68→89 예시가 6↔9 힌트) / 실험 ✓✓(후보 돌려보기 손맛) / 해금 ✓ / 자존감 ✓. 확신 중상.

**6.** `시계 문자판의 열두 숫자를 전부 더하면? (암산 5초 컷이 가능하다)` → **78** ●●
규칙: 1+12, 2+11… 짝짓기 = 13×6. "5초 컷"이라는 도발이 트릭 탐색을 강제.
재미채점: 방황 △(짧음) / 발판 ✓("5초 컷" 선언 자체) / 실험 ✓(짝짓기) / 해금 ✓ / 자존감 ✓(가우스가 된 기분). 확신 중. 암산 상한(기준 21) 이내 — 트릭 쓰면 덧셈 한 번.

**7.** `두 자리 수 AB에 일의 자리 B를 더했더니 자리가 뒤집힌 BA가 됐다. AB는?` → **89** (89+9=98) ●●●
규칙: 유일해 탐색 — 시행착오가 9A=8B 구조로 수렴.
재미채점: 방황 ✓(시행착오) / 발판 ✓(B를 더했는데 뒤집힘 = 강한 제약) / 실험 ✓✓ / 해금 ✓(89+9=98 검산 내장) / 자존감 ✓✓. 확신 중상.

**8.** `1, 10, 11, 100, 101, ?` → **110** ●●
규칙: 이진수로 세기 (1,2,3,4,5,6).
재미채점: 방황 ✓(등차? 등비? 붙여읽기?) / 발판 ✓유형②(모든 항이 0과 1로만!) / 실험 ✓ / 해금 ✓ / 자존감 ✓(학교 지식). 확신 중상.
