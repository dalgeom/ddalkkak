# 발견형 신작 후보 — 배치 1 (28문제, 2026-07-11)

### 수·연산 계열

**1.** `9◇9=9, 7◇8=11, 6◇7=6, 8◇8=?` → **10** ●●
규칙: 곱의 자릿수합 (81→9, 56→11, 42→6, 64→10). 미끼: 첫 예시가 항등처럼 보임(9◇9=9), 6◇7=6도 왼쪽 항등 미끼. 확신 높음.
✅

**2.** `3♥7=3, 2♥9=6, 5♥6=0, 4♥9=?` → **4** ●
규칙: 두 수 사이에 있는 정수의 개수. |차|−1과 동치(무해한 파생 쌍둥이). 확신 높음.
✅

**3.** `8=4, 3=3, 9=2, 6=?` → **2** ●●
규칙: 로마 숫자 표기의 글자 수 (VIII=4, III=3, IX=2, VI=2). 미끼: 8=4가 "÷2"를, 3=3이 항등을 물게 함 — 서로가 서로를 죽임. 확신 높음.
✅

**4.** `12▲=6, 7▲=2, 16▲=5, 24▲=?` → **8** ●●●
규칙: 약수의 개수. 미끼: 12→6이 ÷2를 물게 함(7→2에서 사망). 수학 지식 필요 — 난이도 상한 주의. 확신 중.
✅

**5.** `72☆=45, 91☆=72, 84☆=36, 93☆=?` → **54** ●●
규칙: 자기 자신 − 뒤집은 수 (72−27). 보너스: 91☆=72로 결과가 다음 입력처럼 보이는 사슬 착시. 확신 높음.
✅

**6.** `SEOUL=1, BUSAN=3, DAEGU=2, INCHEON=?` → **1** ●●
규칙: 대문자로 쓴 글자 속 닫힌 공간(구멍) 수 (O=1 / B=2,A=1 / D=1,A=1 / O=1). 미끼: 도시 데이터(인구·순위·음절)로 유인. 확신 높음.
✅

**7.** `거울 속 시계: 3:00→실제 9:00, 2:30→9:30, 6:00→6:00. 그럼 거울 속 4:15의 실제 시각은?` → **7:45** ●●
규칙: 12:00 − 표시 시각. 6:00→6:00 자기대칭이 검산 보너스. 확신 높음.
❌
이유: 뭔가 머리속으로 그려지고, 머리써서 규칙을 찾는 과정이 재밋고 즐거운건데 이런문제는 그냥 찾을 규칙도없고 단순히 거울에 비쳐지는 모습을 그려내기만 하는건데 재미도없고 머리속으로 잘 안그려짐

**8.** [선택지] `호수에 비친 그림자에서도 똑같이 읽히는 단어는? ECHO / LAMP / TREE / MOON` → **ECHO** ●●
규칙: 상하대칭 글자(B C D E H I K O X)로만 구성. 확신 중상.
❌
이유: 재미없음 걍 너무 쉬움. 찾을 규칙 패턴 트릭 같은게 없음

### 생활 지식 계열

**9.** `서울=2, 부산=51, 대구=53, 광주=?` → **62** ●● (구세트 재채점 요청)
규칙: 전화 지역번호(02, 051, 053, 062). 미끼: 글자수(서울=2)가 첫 항만 통과 후 사망. 확신 높음.
❌
이유: 재미없음 걍 너무 쉬움. 찾을 규칙 패턴 트릭 같은게 없음

**10.** `! + @ = #, @ + @ = $, # + % = ?` → **\*** ●● (구세트 재채점 요청)
규칙: 키보드 시프트 숫자 (!=1 … \*=8). 답을 기호로 되돌리는 소재 회귀. 확신 중상.
❌
이유: 재미없음 걍 너무 쉬움. 찾을 규칙 패턴 트릭 같은게 없음

**11.** `1988=용, 2024=용, 2025=뱀, 2033=?` → **소** ●
규칙: 띠(12지 순환). 확신 높음, 쉬움.
❌
이유: 이건 일반적인 상식이 아니라 별로임. 12지를 외우고, 해당 년도가 무슨 띠의 해였는지 외우는 사람은 거의 없음. 일반적인 숫자,영어,한글,알파벳,달력,week,시계, 평범한 영단어, 순서 등등이 아님

**12.** `13층 건물인데 엘리베이터 숫자 버튼은 12개뿐. 없는 숫자는?` → **4** ● (부재 추론)
규칙: 한국 건물의 4층 기피 문화. 확신 중.
✅

**13.** `화투: 1=소나무, 2=매화, 3=벚꽃, 8=?` → **달(공산)** ●●●
규칙: 화투 월별 도안. 지식 편중 심함 — 확신 낮음, 반려 예상.
❌
이유: 재미없고 쉽고 지식 편중 심함

**14.** `VSY=고양이, FPH=개, DIM=해, VPE=?` → **소** ●●●
규칙: 각 글자를 키보드에서 한 칸 왼쪽으로 읽으면 영단어(CAT, DOG, SUN, COW). 미끼: DIM이 진짜 영단어(어둡다≠해)라서 혼란 가중. 확신 높음 — 배치1 대표작.
✅

**15.** `ㄷ ㄹ ㅁ ㅍ ㅅ ㄹ ?` → **ㅅ** ●●
규칙: 도레미파솔라시의 초성. 확신 중상.
✅

**16.** `코끼리=3, 소=1, 개미=2, 지렁이=?` → **3** ●
규칙: 글자 수. 미끼: 동물이라 크기·다리 수로 유인 (개미 다리 6≠2에서 사망). 확신 높음.
✅

**17.** `TENANT=10, CANINE=9, WEIGHT=8, STONE=?` → **1** ●●
규칙: 단어 속에 숨은 수 단어 (TEN, NINE, EIGHT, ONE). 확신 높음.
✅

**18.** `31일이 없는 달은 5개다. 30일이 없는 달은 몇 개?` → **1개(2월)** ●●
규칙: 여집합 관찰 — 31일 있는 달에도 30일은 있다. 기존 유사 문제 존재 — 확신 중하.
✅

**19.** `주사위 3개를 탑으로 쌓았다. 맨 위 면이 4일 때, 밖에서 안 보이는 가로면 5개의 합은?` → **17** ●●●
규칙: 마주보는 면 합 7 → 3 + 7 + 7. 답이 확정된다는 게 아하. 확신 중.
✅

**20.** `시계: 3시=90, 6시=180, 1시=30, 4시=?` → **120** ●
규칙: 정각의 시침 각도(시×30°). 확신 높음, 쉬움.
✅

**21.** `7, 8, 5, 5, 3, ?, 4, 6, 9, 7, 8, 8 (열두 개)` → **4** ●●●
규칙: 1~12월 영어 이름 글자 수 (JUNE=4). "열두 개"가 관찰 단서, 12항 전체 제시로 유일성 조임. 확신 높음.
✅
