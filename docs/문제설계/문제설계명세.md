## PART 1. 문제별 학습 카드

### 카드 1 — TAC=4, TNA=6, GOD=4, NAM GIP=? (답 6)
- **풀이 스킬**: 무의미한 표기를 "뒤집힌 실제 단어"로 재해석 → 단어의 대상을 속성(다리 수)으로 수치화
- **사고의 전환**: 숫자는 계산 결과가 아니라 **대상의 속성**일 수 있다. 글자는 암호가 아니라 변형된 실물이다.
- **설계 원리**: 적용 단계 변형(NAM GIP = 두 단어 → 합산)이 표면 암기를 걸러냄
- **활용**: 속성 매핑 사전 구축(다리 수·바퀴 수·글자 수·변의 개수·다리 개수·음절 수) × 표기 변형(역순·삽입·치환) = 조합 생성 가능

### 카드 2 — 131 / 2x8 / 331 / 430 / 531 / 630 (답 x=2)
- **풀이 스킬**: 파싱(읽기 단위) 재설정 — 세로 열처럼 보여도 가로로 붙여 읽기 → 달력 상식 연결
- **사고의 전환**: **주어진 시각 구조 자체를 의심한다.** 읽기 단위는 출제자가 아니라 내가 정한다.
- **설계 원리**: 배치 자체가 미스디렉션이 될 수 있다
- **활용**: 붙여/끊어 읽기 계열 — 달력, 시각(1230=12시30분), 노선번호, 주민번호 구조 등 일상 숫자 체계로 변주

### 카드 3 — 木=11, 田=2, 干=6, 王工=? (답 53)
- **풀이 스킬**: 예시들의 숨은 공통 성질 관찰(좌우대칭) → 조작(반 절단) → 문자 체계 점프(한자 조각→알파벳) → 순서 지식(K=11)
- **사고의 전환**: 글자를 의미가 아니라 **그림으로 본다**. 규칙 탐색 전에 '관찰'이 먼저다.
- **설계 원리**: 예시 집합의 공통 성질(대칭)이 열쇠를 숨기는 금고 역할
- **활용**: 문자=도형 변환 라이브러리(절단·회전·거울·겹침) × 도착 체계(알파벳·한글·숫자). 대칭 한자/한글 DB는 코드로 전수 추출 가능
- **AI 실패 기록**: 절단이라는 조작을 착상 못 함 → 조작 체크리스트 필요성

### 카드 4 — 색 사각형 격자 =???? (답 1172)
- **풀이 스킬**: 색-회색 경계선이라는 새 층위 발견 → 한글 자음 → 자음 순번. 마름모(회전)에 규칙의 본질 적용
- **사고의 전환**: **모든 요소의 역할을 재배정해 본다** — 색은 장식이 아니라 경계 생성기였다. 그리고 예시를 다 통과하는 규칙도 오답일 수 있다.
- **설계 원리**: ① 대안 규칙 공격의 필요성(AI가 위치번호 규칙으로 13까지 맞춘 오답 실증) ② 마름모 원칙 — 적용 단계 변형이 좌표 암기와 본질 이해를 가름
- **활용**: 한글 자음/모음을 격자 경계선으로 렌더링하는 생성기 제작 가능. 검수에 "대안 규칙 조립 공격" 단계 필수화

### 카드 5 — 6128+9091=9825, 8159+1912=? (답 8679)
- **풀이 스킬**: 재료의 메타 단서 읽기(LCD 서체 = 회전 가능, 3·4·7 부재 = 뒤집기 가능 숫자만) → 180° 회전 → 검산
- **사고의 전환**: **출제자의 재료 선택에서 의도를 역추적한다.** "왜 하필 이 서체, 이 숫자들인가?"
- **설계 원리**: 내장 검산(규칙이 맞으면 산수가 완벽히 떨어짐) = 최상급 구조. 우연 성립 확률 사실상 0
- **활용**: 코드로 대량 생성 최적 — "뒤집은 두 수의 합이 표시값" 항등식을 전수 탐색으로 채굴 가능. 회전·거울 불변 숫자/글자 조합 생성기

### 카드 6 — 5글자 리들 (답 ALONE→LONE→ONE)
- **풀이 스킬**: 조건 → 대상 역탐색. 언어의 성질(베어내도 의미 보존) 인지
- **사고의 전환**: 규칙 귀납과 반대 방향의 사고 — **조건을 만족하는 놈을 찾아라.** 문제 형식이 다르면 사고의 방향도 뒤집힌다.
- **설계 원리**: 조건 탐색형 축의 발견. 어원(alone=all one)까지 맞물리면 명작
- **활용**: 한국어판 후보를 사전 데이터 전수 탐색으로 채굴 (한가운데→가운데, 온종일→종일). 2단 생존 단어를 찾으면 ALONE급

### 카드 7 — 버스 방향 (답 왼쪽)
- **풀이 스킬**: 부재 추론 — 그려지지 않은 것(문)이 단서 → 생활 지식(우측통행, 문 위치) 결합
- **사고의 전환**: **"있는 것"만 분석하는 습관을 깬다.** 어른은 화살표를 분석하고 아이는 문이 없다는 걸 본다.
- **설계 원리**: 정답이 지역 규칙(통행 방향)에 의존 → 전제 확인 기준 추가
- **활용**: "그림에 없는 것" 시리즈 기획 가능. 지역 전제는 한국 기준으로 명시

### 카드 8 — 스트립 A~F 재배열 (답 D,F↻,C↻,E,A,B)
- **풀이 스킬**: 탐색 공간 재정의(조각은 움직인다!) + 제약 전파(=은 행당 1개 → 숫자-only 스트립이 양끝 → 회전 후보 축소)
- **사고의 전환**: **무의식적 전제("배치는 고정")를 명시화하고 깨라.** 읽는 문제가 아니라 만지는 문제일 수 있다.
- **설계 원리**: 조립형 축의 발견. LCD 서체가 여기선 "조각 회전 가능"을 위해 기능 — 같은 도구의 다른 기능
- **활용**: 웹 드래그 인터랙티브 문제로 최적(우리 사이트의 차별화 포인트). 제약 충족 문제는 코드로 생성·검증이 가장 쉬움
- **AI 실패 기록**: 고정 배치 전제로 가설 40개를 헛돌림 → "전제 명시화" 절차 필요

### 카드 9 — MON=3, TUE=5, WED=4, THU=? (답 6)
- **풀이 스킬**: 위상적 시선 — 글자를 그래프(홀수점)로 보고 한붓그리기 최소 획수 계산 (T=2, H=3, U=1)
- **사고의 전환**: ① **소재가 가리키는 지식 체계(요일→달력·행성)는 통째로 미끼일 수 있다** — 소재와 규칙의 분리 ② 같은 "획수"에도 셈법이 여럿이다(필기 획수 ≠ 한붓그리기 획수)
- **설계 원리**: 강한 연상을 가진 소재일수록 좋은 미끼. "부분 일치의 저주"(E=5, D=4 같은 우연 파편)가 자연 발생하면 난이도 급상승
- **활용**: 한붓그리기 획수 계산기는 코드로 자동화(홀수점÷2) → 아무 글자·단어로 변주 무한. 소재-규칙 분리 원칙을 생성 공식에 편입
- **AI 실패 기록**: 8번 분석에서 홀수점 도구를 쓰고도 여기 적용 못 함 → 도구 보유 ≠ 도구 적용. 셈법 체크리스트로 강제할 것

### 카드 10 — 손가락 등식 (1=5, 2=2, 4=3, 5=2 … 5+3손가락=?) (답 0 주먹)
- **풀이 스킬**: 손가락 수 → 7세그먼트 디지털 표시로 표상 전환 → **켜진 칸이 아니라 꺼진 칸을 센다** (여집합 시선)
- **사고의 전환**: ① 아날로그(신체)를 디지털(세그먼트)로 옮기는 역방향 점프 ② "사용되지 않은 것"이 답이다 — 버스 문제(없는 문)에 이은 두 번째 부재·여집합 문제
- **설계 원리**: 소재(손가락)가 수세기·신체 연상으로 유인하는 미끼, 규칙은 전혀 다른 층위(디지털 표시) — 소재-규칙 분리의 모범. 정답(주먹=0)이 다시 소재의 언어로 표현되는 수미상관 마무리
- **활용**: 여집합 변주 무한 — 꺼진 세그먼트, 접힌 손가락, 안 쓰인 글자, 비는 요일. "정답을 소재의 언어로 되돌리기"를 생성 공식의 마감 기법으로 채택
- **AI 실패 기록**: ① 7세그먼트 도구를 카드 5에서 쓰고도 소재가 손가락이라 가설에서 제외 — 소재 연상에 풀이자가 낚이는 것을 스스로 재실증 ② 이미지 오독 2연속(3=2를 3=3으로, 5+3을 4+3으로) → 이미지 문제는 판독 목록화+확신도 표기 먼저

### 카드 11 — 2★3=9, 5★4=26, 6★2=13, 7★4=? (답 34)
- **풀이 스킬**: 연산자 재정의 귀납 — 결과값을 분해(26 = 5+6+7+8)해서 절차를 역추적. "a부터 연속 b개의 합"
- **사고의 전환**: ① ★는 사칙연산의 조합이 아니라 **절차(알고리즘)**일 수 있다 ② "산수 실패 → 수학 버려라"는 휴리스틱의 반례 — 수학이 맞는데 연산이 재정의된 경우가 있다
- **설계 원리**: 자연 발생 부분 일치 미끼(a×b+(a+1)이 3예시 중 2개 통과)가 난이도를 만듦. 예시 3개가 미끼를 정확히 죽이는 최소 구성
- **활용**: 연산자 귀납형은 코드 생성 최적 — 절차 라이브러리(연속합, 자릿수 조작, 곱+차, 계승 등)에서 뽑아 예시 자동 산출 + 대안 규칙(다항식 근사) 자동 공격 가능. 예시 개수는 "그럴듯한 오답 규칙이 전부 죽는 최소 개수"로 설정
- **성공 기록**: 힌트 없이 해결. 부분 일치 미끼(2/3 통과 규칙)를 인지하고 버린 뒤 분해 접근으로 전환한 것이 주효

### 카드 12 — 19−18=18에 선 하나 긋기 (답: 왼쪽 18을 가로로 관통 → 10/10 → 19−1=18)
- **풀이 스킬**: "선"의 의미론 전체 순회 — 추가·삭제·삽입뿐 아니라 **절단(글자 쪼개기) + 표기(분수선) 겸용**. 가로 절단: 1→1/1, 8→0/0
- **사고의 전환**: ① 선 하나가 여러 기능을 동시에 수행할 수 있다(절단기 + 분수 기호) ② 절단 조작은 문자 퍼즐 전용이 아니다 — 조작은 맥락 무관 전 유형에 순회할 것
- **설계 원리**: ① 단서 문구("등호 불가")가 1순위 미끼(≠)를 명시 차단해 깊은 탐색을 강제하는 기법 ② 요소 다기능의 극한 — 획 하나가 3역할 ③ 단, 오른쪽 18에 그어도 성립(19−18=10/10, 1=1)하는 복수 배치 문제 존재 → 생성 시 배치 유일성까지 조일 것
- **활용**: 절단→분수 메커니즘의 변주 채굴 — 가로로 잘라 의미가 생기는 숫자쌍(8→0/0, 1→1/1, 3→?)을 코드로 탐색해 "선 하나" 시리즈 양산 가능. 편집형(최소 조작 교정)을 제4의 출제 형식으로 등록
- **AI 실패 기록**: 취소선(삭제)까지만 도달, 절단+표기 겸용 미도달. **도구 보유-미적용 3호** (9번 홀수점, 10번 7세그, 12번 절단) — 도구를 특정 맥락에 가두는 버릇이 근본 원인

### 카드 13 — 5+3=28, 9+1=810, 8+6=214, 5+4=19, 7+3=? (답 410)
- **풀이 스킬**: 결과값을 문자열로 분해 — [차이][합]의 이어 붙임. 자릿수 변동(2~3자리)과 810의 비정상 크기가 "결과 = 합성 문자열"이라는 메타 단서
- **사고의 전환**: 등식의 우변이 수가 아니라 **두 답을 이어 쓴 표기**일 수 있다 — 산술의 세계에서 문자열의 세계로 절반만 건너간 하이브리드
- **설계 원리**: 첫 예시(5+3=28)만으로는 오답 규칙 다수 허용 → 뒤 예시들이 차례로 죽임. 자릿수가 변하는 예시(810)를 반드시 포함해야 "이어 붙임"을 발견 가능하게 함
- **활용**: [f(a,b)][g(a,b)] 조합 생성기 — 차·합·곱·자릿수합 등 함수쌍으로 무한 변주, 정답 보장. 단 대안 규칙 공격 필수(함수쌍이 단순할수록 다항 근사 오답이 생존하기 쉬움)
- **성공 기록**: 힌트 없이 해결. 체크리스트 "결과값 분해부터"가 직행 경로였음 — 도구 적용 성공 사례

### 카드 14 — 9 여섯 개로 100 만들기 (답: 99+99/99 외 복수 해)
- **풀이 스킬**: 목표 역산(100 = 99+1 / 900÷9 / 81+18+1처럼 큰 덩어리+미세조정으로 분해) + 재료 결합 자유도 인지(9를 이어 붙여 99·999 허용)
- **사고의 전환**: 재료는 낱개가 아니라 **이어 붙여 다자리 수로 쓸 수 있다** — 붙여 읽기(카드 2)의 '구성' 버전. 그리고 구성 문제는 정답이 하나가 아닐 수 있다
- **설계 원리**: 구성형은 복수 해가 기본값 — 사이트에서는 "아무 해나 인정" 채점기(파서로 검증) 또는 "가장 짧은/연산 최소 해 찾기" 경쟁 모드로 설계. 제약(숫자 종류·개수·연산 허용 범위)이 난이도 조절 다이얼
- **활용**: 완전 자동화 가능 계열 1순위 — 표현식 전수 탐색으로 (재료, 목표) 쌍의 해 존재·개수·최단 해를 사전 계산해 문제 은행 구축. "4개의 4", "올해 연도 숫자로 1~100" 등 검증된 하위 장르 존재
- **성공 기록**: 자력 해결 (복수 해 3종 제시)

### 카드 15 — 수열 10, 4, 60, 90, 70, 18, ? (답: 9글자 수 — 의도는 96 추정)

### 카드 21 — 1556+3174=3998 (LCD), 2174+6935=? (답 8939)

**개수 불일치는 구조 선언**: 두 그룹이 n개 vs n+1개면 상태-전이 사슬(상태 n+1, 전이 n) 가설을 최우선 실행 (카드 20). 정적 매핑만 돌리다 사슬을 놓치지 말 것

**철칙: 닮음은 조작으로 승격해야 정답** — "X가 숫자 Y를 닮았다"로 값이 맞으면, 반드시 "어떤 정밀 조작(획 제거·절단 등)이 X를 Y로 만드는가"를 찾아 통일 규칙으로 승격할 것. 조작 없는 닮음은 적용 단계에서 배신한다 (카드 16: T≈7 닮음 vs T−가로=1 조작)

**도착 체계**: 영단어 / 알파벳 순번 / 한글 자음·모음 순번 / 한자 / 달력·시계 / 키보드·키패드 / 화폐 / 지역번호 / 모스 / 로마 숫자 / 속성 사전(다리 수 등)

**절차**: ① 산수 실패 확인 ② 재료 메타 단서(서체·색·부재·구성 편중) ③ 예시 공통 성질 관찰 ④ 조작×체계 조합 스윕 ⑤ 전제 명시화(고정? 이동 가능?) ⑥ 규칙 후보 → 전 예시 검산 ⑦ "딸깍" 없으면 오답 취급하고 계속

- 무슨 일: 기존 100문제와 발견이 겹치지 않게 하려고 규칙 목록을 워크플로우 프롬프트에 넣었는데, **해설 앞 75자로 잘라서** 만들었다. 세 규칙이 전부 75자 뒤에 있어 출제자 6레인도, 적대적 검수관 3팀도 볼 수 없었다. 결과적으로 7문제 중 3문제가 기존 문제와 같은 발견이었다.
  - `alpha-ascend` ↔ `consonant-asc-club`(차례차례 클럽): 알파벳 오름차순. **회원 단어 BEGIN·CHIMP까지 그대로 겹침.**
  - `weekday-batchim` ↔ `batchim`: "수 이름의 받침" 과 동일 발견, 소재만 요일로 교체.
  - `calendar-length` ↔ `day-7777`·`friday-13`: mod 7 요일 산술이 이미 2문제.
- 어떻게 걸렸나: 자동 검수는 전부 통과했다. **라이브에서 직접 20문제를 워크스루하다가** 기존 '차례차례 클럽'이 화면에 뜨면서 눈으로 잡았다.
- 교훈 1 — **중복 판정 입력은 절대 요약·절단하지 않는다.** 발견 메커니즘은 해설 뒷부분에 적히는 경우가 많다. 토큰이 아까우면 배치 크기를 줄이지, 대조 자료를 줄이면 안 된다.
- 교훈 2 — **"소재만 바꾼 같은 발견"이 가장 잡기 어려운 중복이다.** 받침(수 이름 → 요일)처럼 표면 어휘가 다르면 문자열 비교로도 LLM 검수로도 안 걸린다. 대조는 소재가 아니라 *발견 메커니즘* 단위로 물어야 한다.

- **연쇄 해금**: 자르니 알파벳(1차), 알파벳=순서=숫자(2차) — 해금이 다단으로 터지며 문자 체계 3개를 관통할 때 최대 재미
- **발판의 유형**: ①데이터 속 부분 패턴(31/30 반복) ②모든 예시의 숨은 공통 성질(좌우대칭) ③이상치(810의 크기, 수열 차이의 단발 튐) ④구조의 어긋남(카드 20: 윗줄 아래줄 개수 불일치 → "번갈아 봐야 하나?" 구조 가설 유발) ⑤지각 반전(시각형 전용, 카드 4: 오래 응시하다 어느 순간 ㄱ·ㅁ이 '보임' — 게슈탈트 팝아웃. 시각형은 잠복이 길어도 재미 유지, 방황 허용 시간이 텍스트형보다 김)

**카드 20 사례 (사용자 원문)**: 좌→우로 읽으며 배열 규칙 방황 → "왜 두 줄의 개수가 다르지?"(발판 ④) → 번갈아 읽기 가설 → 더하기 실험 → 해금. 3사례 모두 동일 뼈대임을 사용자가 확인 — 이론 폐합.

**배치 4부터 재미 자가 채점 5항목**: ①방황 유발 가설이 3개 이상 자연 발생하는가 ②발판이 심겨 있는가(유형 명시) ③실험 행위 단계가 있는가 ④해금이 한 걸음에 전체를 여는가(연쇄면 가점) ⑤"내가 풀었다" 높이인가(지식 확인·노동이 아닌가)

**반려작 재해석**: 1홉 = 방황 없음(빌드업 0) / 四·곱셈지속성 = 발판 없음(닿을 수 없는 높이) / 서수·어원 = 풀어도 "내가 해낸 것"이 아님(지식 확인)

**생성 체크**: ① 방황을 유발할 가설 후보가 3개 이상 자연 발생하는가 ② 데이터에 발판(부분 패턴)이 심겨 있는가 ③ 발판에서 해금까지 한 걸음인가 ④ 답을 보고 "내가 풀 수 있었는데!"가 아니라 "내가 풀었다!"가 되는 높이인가

## PART 8. 양산 전략 (2026-07-11 확정)

**핵심 구분**: ① 규칙 발견형 — 재미 = 일회성 딸깍. 같은 규칙 반복 금지(사용자의 21예시도 규칙이 전부 달랐음). "×100" = 서로 다른 숨은 규칙 100개를 의미해야 함. 현 카탈로그 기준 신규 규칙 여력 150~300개 추정. ② 절차 실행형(조립·편집·구성·최적화) — 규칙 공개, 매판 탐색이 재미(스도쿠 모델). 코드 생성+유일해 증명으로 무제한 양산 가능.
