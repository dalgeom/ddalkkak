# 발견형 신작 후보 — 배치 5 (18문제, 2026-07-12)

목표 200개 향한 첫 대량 사이클. 그리드 스윕(미사용 체계: 촌수·방위·다의어·빛·가위바위보·키패드 등) + 통과 틀 시리즈화(클럽 3연작).
전 문제 재미 자가 채점 통과분만 수록. 채점: ✅/❌(+이유).

---

### 생활 체계 계열

**1.** `아버지와는 1촌, 형과는 2촌, 삼촌과는 3촌. 그럼 삼촌의 아들과는?` → **4촌** ●●
발판: **삼촌 이름 속의 3** — 호칭이 곧 숫자였다는 각성 → 경로 세기로 적용. 확신 중상.
❌
이유: 재미없음

**2.** `북=0, 동=90, 남=180, 서=?` → **270** ●
나침반 각도(시계방향). 워밍업 슬롯. 확신 중상.
❌
이유: 재미없음

**3.** `바위=0, 가위=2, 보=?` → **5** ●●
펼친 손가락 수. 미끼: 승패 관계·순서. 확신 높음.
✅ 재미없고 너무쉽긴한데 그래도 그나마 봐줄만함

**4.** `어떤 달의 13일이 금요일이다. 그 달 1일은 무슨 요일?` → **일요일** ●●
발판: 13−7=6일도 금요일 → 거꾸로 세기. 확신 중상.
✅ 재미없고 너무쉽긴한데 그래도 그나마 출제할만함

**5.** `달력에서 가로로 나란한 세 날짜의 합이 45다. 가운데 날짜는?` → **15** ●●
발판: 연속한 세 수의 가운데 = 평균. 암산 상한 이내. 확신 중상.
✅

**6.** `일 년 내내, 어떤 달력에도 인쇄되지 않는 가장 작은 수는?` → **32** ●
여집합 관찰. 확신 중.
✅

**7.** `우리 가족 나이의 합은 작년보다 정확히 4 많다. 우리 가족은 몇 명?` → **4명** ●●●
발판: 1년에 모두 +1살 → 증가량 = 인원수. "계산 불가능해 보임"이 미끼. 확신 중상.
❌
이유: 재미없음

**8.** `주사위에서 마주보는 두 면의 곱이 가장 클 때, 그 값은?` → **12** ●●
합 7 지식 → (1,6)(2,5)(3,4) 중 곱 최대는 가운데 쌍이라는 실험. 확신 중.
✅ 재미없고 너무쉽긴한데 그래도 그나마 출제할만함

**9.** `6시 정각, 시침과 분침의 각도는 180도. 그럼 6시 30분에는?` → **15도** ●●●
미끼: **0도**(분침이 6에 오니 겹친다는 착각) — 시침도 움직인다는 발견. 확신 높음.
✅

### 클럽 3연작 (미끼 서사형)

**10.** [선택지] `클럽: SKY ✓ GYM ✓ FLY ✓ — SUN은 거절당했다. 이유는?` [모음(AEIOU)이 없어서 / 세 글자라서 / 하늘과 관련 없어서 / 발음이 짧아서] → **모음 없음** ●●●
미끼: 하늘 테마(GYM이 죽임), 글자 수(SUN도 3글자 — 선택지가 직접 죽여줌). 확신 중상.
✅

**11.** [선택지] `클럽: 4 ✓ 6 ✓ 8 ✓ 9 ✓ — 7과 11은 거절. 다음 중 회원은?` [13 / 15 / 17 / 19] → **15** ●●
미끼: 짝수 클럽(9가 회원이라 사망) → 거절 목록이 전부 소수라는 발견. 확신 중상.
✅

**12.** `클럽 회원: 1·3·5·7·8·10·12 — 거절: 2·4·6·9·11. 회원의 조건은?` → **31일까지 있는 달** ●●●
발판: **7과 8이 연속 회원**(홀짝 규칙 전멸). 확신 중상.
✅

### 언어 계열

**13.** `숫자이면서, 뜨겁기도 하고, 나란히 서 있기도 한 한 글자는?` → **열** ●●
다의어 수수께끼 (10 / 열나다 / 열 맞춰). 확신 중.
✅

**14.** `곱하기이고, 모르는 수이고, 로마에서는 10인 것은?` → **X** ●●
기호 다의어. 확신 중상.
✅ 이런건 문제는 괜찮은데 문제 출제를 할 때 '나는 사칙연산 기호입니다' '나는 모르는 수 입니다' 나는 로마숫자입니다' '나는 무엇일까요?'
이런식으로 문제를 내야 좀 더 문제답고 맞출만하고 그렇지 않겠어?

**15.** `영어 나라: 8=먹었다, 4=~를 위해, 2=~에게. 그럼 1=?` → **이겼다(WON)** ●●●
동음이의 숫자(ATE·FOR·TO·WON). 애너그램 수(배포)와 다른 축 — 소리. 확신 중상.
✅

**16.** `SCARF=자동차, BUSY=버스, STRAIN=기차. 그럼 PLANET=?` → **비행기** ●●
단어 속에 숨은 탈것(CAR·BUS·TRAIN·PLANE). 미끼: 단어의 뜻(목도리가 왜 차?). 확신 높음.
❌
이유: 재미없음 너무쉬움

### 시각·과학 계열

**17.** [전광판 렌더] `5→6, 6→8, 3→9, 0→?` → **8** ●●●
규칙: 획 하나가 켜지면 다른 숫자로 진화. 미끼: 산술(+1, +2, +6으로 불규칙 사망). 자연 미끼 강함. 확신 높음.
✅

**18.** `화면 속 빛의 세계: 빨강+초록=노랑, 초록+파랑=청록. 빨강+초록+파랑=?` → **흰색** ●●●
빛의 혼합(RGB) — 미끼가 **물감 상식 그 자체**("빨+초=노랑?!"에서 이미 상식 붕괴). 기배포된 물감 문제와 대구. 확신 중상.
❌
이유: 이게 일반상식인가 싶음. 물감3개 섞었을 경우, 또는 빛 3개 합쳤을 경우의 색을 아는사람이 일반적으로 많아?
