요약

  • v1 보고서가 지적한 문제는 모두 손댔습니다. 고장 4개(전개도 링크, 안 눌리는 카드, 상식 견본, 알림 중복)는 고쳐졌고 운영에서 확인했습니다.
  • 화면 틀을 하나로 맞췄습니다. 안내 화면 22개가 같은 머리를 쓰고, 유형 홈은 모두 「어떻게 풀까요?」로 시작합니다. 상식 홈은 8,745px에서 2,953px로 줄었습니다.
  • 「오늘 · 놀이 · 기록」 하단 탭, 놀이 허브, 새 소식, 오늘의 미션, 집중 풀이 화면, 상식 대결을 새로 열었습니다.
  • 결과 화면은 11가지에서 다섯 덩어리(점수 · 알림 · 공유 · 내 기록 · 다음 놀이)로 줄었습니다. 1번 문제 이탈은 수학 패턴류 5문제를 1번에서 뺀 것까지만 했습니다.
  • 재점검에서 운영에 나가 있던 문제 2개를 고쳤습니다. 새 소식이 닫아도 다시 뜨던 버그, 그리고 57개 화면에서 구역 사이 여백이 사라져 카드가 붙고 카드 속 카드가 된 것입니다. 뒤의 것은 사용자가 기록 화면에서 먼저 찾았고, 제 점검은 화면을 보면서도 간격을 재지 않아 놓쳤습니다.
  • 저녁에 사용자가 다섯 가지를 더 찾았습니다(구역 붙음 · 시트 ✕와 끌어 닫기 · 닫을 때 깜빡임 · 하단 탭이 아이폰 홈 바에 걸림 · 스플래시 반복). 모두 고쳤고, 같은 일이 되풀이되지 않도록 점검 묶음 npm run qa를 만들어 화면을 바꾸면 통과 전에는 완료 보고를 하지 않기로 했습니다(9절).
  • 효과는 아직 숫자로 확인되지 않았습니다. 오늘 배포했고, 10/21부터 11/4까지 판정합니다. 한꺼번에 바꿔서 항목별 효과는 나눠 볼 수 없습니다.
